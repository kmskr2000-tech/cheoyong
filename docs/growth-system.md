# 「신 처용가」 성장 시스템

> 원칙: 이 게임에서 몬스터를 "죽이는" 것이 아니라 "정화"한다.
> 그래서 전리품도 시체가 아니라 **맑아진 기운**이다.

---

## 1. 핵심 루프

```
몬스터 정화 → 정기 + 덕망 (+ 엽전 소량) → 성장
                ├─ 정기 → 피리/탈 강화, 부적·퇴치향 제작
                ├─ 엽전 → 상점 구매 (약재·재료·소모품)
                ├─ 덕망 → 레벨업 → 스킬 포인트 → 스킬 트리
                ├─ 한풀이 보너스 → 정화율 100% 달성 시 1.5배
                └─ 요괴 도감 → 수집 완성 보너스
```

**몬스터와 싸우는 이유 4가지**: 정기 파밍 / 덕망 / 한풀이 보너스 / 도감 수집.
어느 것도 놓치면 손해인 구조.

## 2. 재화 3종

| 재화 | 획득처 | 용도 |
|---|---|---|
| **덕망(德望)** | 정화, 의뢰 완료 | 레벨업 → 스킬 포인트 (기존 시스템 유지) |
| **정기(精氣)** | 정화 시 탁기가 맑아지며 응결 | 피리·탈 강화, 부적 제작, 퇴치향 제작 (**상점에서는 쓰지 않는다**) |
| **엽전(葉錢)** | 의뢰 보상, 재료 판매, 정화 시 소량 | **상점 구매 전용** (약재·재료·소모품) |

- 역할 분리: 정기 = 처용의 힘(성장), 엽전 = 사람 세상의 돈(거래). 정기는 사고팔 수 없다.

- 정기 획득량: 일반몹 5~15 / 정예 30~50 / 보스 200~
- 한풀이(정화율 100%) 달성 시 정기·덕망 1.5배 (기존 한풀이 연출과 연동)

## 3. 장비 — 한국 테마

### 피리 (무기)
| 단계 | 이름 | 해금 |
|---|---|---|
| 1 | 대나무 피리 | 시작 (백사장에서 주움) |
| 2 | 오동 피리 | 1장 클리어 후 제작 |
| 3 | 학 피리 | 2장 도깨비 상점 |
| 4 | 용문 피리 | 4장 용궁 |
| 5 | 천년 피리 | 5장 서천꽃밭 재료 |

- 강화: 정기 소모, 1~10강. 강당 공격력 +8%, 정화력 +5%.
- 강화 비용: 다음 강 × 100 정기.
- 한계 돌파 (5강→6강): 보스 재료 필요 (예: 역신의 가면 조각).

### 탈 (방어구)
| 탈 | 효과 | 획득 |
|---|---|---|
| 무탈 | — | 시작 |
| 처용탈 | 받는 데미지 -10% | 1장 (마을 사람들이 걸어준 탈) |
| 오방탈 | 정화 속도 +20% | 2장 (두억시니의 답례) |
| 여우탈 | 매혹·환술 내성 | 3장 (연화의 유품, 한풀이 시) |
| 용탈 | 전 상태이상 내성 + HP +50 | 4장 (용왕의 하사) |
| 신선탈 | 처용무 데미지 +30% | 5장 (서천꽃밭) |

### 부적 (스킬)
- 5종: 화염부·결박부·수호부 (1장) + 2종 추가 (2~4장).
- 제작·강화: 재료(몬스터 드롭) + 정기.

### 장신구 (보스·정예 드롭)
- 여의주 조각 (뇌룡), 여우 구슬 (연화), 도깨비 감투 (두억시니), 역신의 눈물 (역신)…
- 효과: 패시브 (드롭률 증가, 정화 속도, 이동 속도 등). 2개 장착.

## 4. 스킬 트리 — 소리 · 춤 · 가호

- 레벨업 → 수련 점수 1점. Lv.1→30이면 **총 29점**.
- **비용**: 1단·2단 1점, 3단 2점, 비전(캡스톤) 3점. 한 계열 전부 = 소리 14점 · 춤 13점 · 가호 13점, 합계 40점 → 29점으로는 **한 계열 완성 + 다른 계열 절반** 정도. 빌드 선택이 강제된다.
- **선행**: 2단은 같은 계열 1단 2개, 3단은 2단 2개, 비전은 3단 1개.
- **가호 계열은 4장(용궁)에서 열린다** (`Game.flag("gaho")`).
- 원칙: 단순 +%가 아니라 **플레이 감각이 바뀌는** 수 위주. 처용가 강화는 스토리 보상(구절 완성)으로 분리 — 트리는 빌드 선택에만.
- 조작은 모바일 버튼 기준(베기·구르기·부적·처용가). 키 표기는 쓰지 않는다.
- 총 28수. ✅ = 지금 게임에서 동작(20수), ⏳ = 바탕 기능(분신·아군화·속성·상태이상 체계·탐지)이 들어온 뒤 해금.

### 기본 전투 (웹판에서 이식, 스킬 없이도 있는 것)
- **부적 3종** (부적 버튼으로 발동, 작은 전환 버튼으로 바꿈 · 대기 1초, 소리=기력 소모):
  화염부(25) 앞 부채꼴 불길 3초, 0.3초마다 5 피해 · 결박부(30) 가장 가까운 요괴 발밑 결계 8초, 안의 요괴 이동 35%, 0.5초마다 2 피해 · 수호부(20) 10초간 다음 한 대를 막음.
  해태는 화염부의 불을 삼킨다(결계마다 한 번 회복).
- **신명 게이지**: 베기 적중 +2.5, 받아넘기기 +15. 가득 차면 **처용무** 버튼이 나타나 빛난다.
- **처용무**: 6초 무적 난무, 0.2초마다 반경 70 안 요괴 30 피해 (보스는 12%만 — 춤 한 번에 체력 2할 남짓).
- **받아넘기기**는 춤 1단 수다: 구르기 시작 0.25초 안에 맞을 뻔하면 시간이 0.35배로 느려지고 다음 베기 ×2, 신명 +15. 10초 안에 3번이면 신명 고조(5초간 이동 +20%, 베기 속도 +30%).

## 5. 요괴 도감

- 정화한 요괴가 자동 등록. 종류별 (일반/정예/보스).
- 완성 보상:
  - 종류 50%: 정기 500
  - 종류 100%: 칭호 "요괴의 벗" + 정화 속도 +10%
- 도감 설명은 각 요괴의 설화 원전 한 줄 포함 (교육적 요소).

## 7. 기획안과의 정합성

- 기획안 §9 (성장 시스템)를 확장. 덕망·스킬트리·굿 의식은 유지.
- 신규: 정기 재화, 피리 5단계·탈 6종·장신구, 요괴 도감, 스탯, 마스터리.
- 상점 화폐(엽전)와 정기는 **분리한다**. 상점 구매는 엽전, 강화·제작은 정기.

## 8. 스탯 — 위쳐식 자동 성장 (수동 분배 없음)

- 위쳐3에 스탯 분배는 없다. 레벨업하면 HP/공격력/방어력이 자동 상승하고, 플레이어의 선택은 스킬·장비에서 나온다. 본 게임도 동일.
- 레벨업 시: 기본 수치 자동 상승 (고정 성장곡선) + 스킬 포인트 1 (3계열 트리).
- 빌드 차별화는 **장비 세트 효과**와 **스킬 조합**이 담당.

### 장비 세트 효과 (위쳐의 학파 장비처럼)

| 세트 | 구성 (피리+탈+장신구) | 2셋 효과 | 3셋 효과 |
|---|---|---|---|
| 용궁 세트 | 용문 피리 + 용탈 + 여의주 조각 | 받는 데미지 -10% | 물 속성 +25%, 정화 속도 +10% |
| 도깨비 세트 | 학 피리 + 오방탈 + 도깨비 감투 | 드롭률 +20% | 정기 획득 +15% |
| 처용 세트 | 천년 피리 + 신선탈 + 처용탈 | 정화 속도 +15% | 한풀이 보너스 +10% |

- 세트는 "같은 테마 장비"를 모으는 수집 욕구와 직결. (도감과 함께 수집 2축)

## 9. 마스터리 — 쓰면 는다

사용 횟수로 오르는 숙련도. 플레이 스타일이 그대로 강해진다.

| 마스터리 | 올리는 법 | 단계 효과 |
|---|---|---|
| **피리** | 베기 적중 횟수 | 데미지 +5/10/15/25% |
| **부적** | 부적 발동 횟수 (부적별 개별) | 위력·지속시간 증가 |
| **춤** | 구르기 회피 성공 횟수 | 무적시간 +0.05초/단계, 쿨다운 감소 |
| **노래** | 처용가 정화량 | 정화 속도 증가 |

- 단계: 입문 → 초심(100회) → 숙련(300회) → 달인(600회) → 명인(1000회).
- 캐릭터 화면에 표시. "춤의 달인" 같은 호칭이 붙는다.
- 마스터리는 **몬스터와 싸울 또 하나의 이유**: 쓰지 않으면 안 는다.

## 10. 성장 4축 요약 (개발용)

| 축 | 재원 | 성격 |
|---|---|---|
| 레벨 | 자동 성장 | 기본 수치 상승 (선택 없음, 위쳐식) |
| 스킬 | 레벨업 (스킬 포인트 1) | 새 능력·패시브 (3계열 트리) |
| 마스터리 | 사용 횟수 | 습관 기반 숙련도 (4단계) |
| 장비 | 정기·재료 (파밍) | 피리·탈·부적·장신구 + 세트 효과 |

- 핵심 루프 (갱신): 정화 → 정기+덕망 → [레벨업·스킬·장비 성장] + [전투 사용 → 마스터리 성장] + [도감·세트 수집] + [의뢰 확인 → 퇴치향 준비 → 출정]

## 11. 퇴치향 — 위쳐의 오일

피리에 바르는 향. 요괴 종류별 특효. 위쳐식 "사전 준비"의 맛.

- 효과: 해당 종류 대상 **데미지 +25%, 정화 속도 +10%**. 지속 30회 타격.
- 한 번에 하나의 향만 (새로 바르면 덮어쓰기).
- 제작: 휴식 지점(집·야영지)에서 재료+정기로 제작. 부족한 재료는 상점에서 엽전으로 살 수 있다.

| 향 | 대상 요괴 | 재료 |
|---|---|---|
| 도깨비향 | 도깨비류 | 도깨비 재료 + 정기 50 |
| 귀신향 | 원혼·처녀귀신·물귀신·달걀귀신 | 귀신 재료 + 정기 50 |
| 역병향 | 역신·마마귀신 등 역병 계열 | 역병 재료 + 정기 80 |
| 여우향 | 여우류 | 여우 재료 + 정기 80 |
| 용향 | 이무기·물 요괴 | 물 요괴 재료 + 정기 100 |
| 저승향 | 망자·저승 계열 | 저승 재료 + 정기 100 |

- 플레이 루프: 의뢰 게시판에서 요괴 종류 파악 → 맞는 향 제작 → 출정.
- 재료는 해당 종류 요괴 정화 시 드롭 → "잡아본 놈은 더 잘 잡는다"는 구조.
