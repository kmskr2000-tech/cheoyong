## Summary

처용이 요괴를 상대하는 실시간 액션의 뼈대다. 대금 3연타, 무적 구르기와 그 보너스인 받아넘기기, 베기·받아넘기기로 차오르는 신명 게이지와 6초 무적 난무 처용무, 소리(기력)를 쓰는 부적 4종을 다룬다. 요괴를 "쓰러뜨리는" 데까지가 이 시스템이고, 쓰러진 뒤의 처용가·보상은 `purification.md`가 맡는다.

> **Quick reference** — Layer: `Core` · Priority: `MVP` · Key deps: `플레이어 컨트롤러(#2)`, 하류: `정화(#6)`, `부적(#7)`, `적 AI(#8)`, `보스(#11)`, `성장 코어(#13)`, `스킬 트리(#14)`

## Overview

탑다운 실시간 전투다(웨이워드 소울즈식 전투 + 위쳐식 "검+사인+회피"의 한국 퇴마 번역, `game-concept.md`). 플레이어는 이동 스틱과 버튼(베기·구르기·부적·부적 전환·처용무·처용가)으로 싸운다. 베기는 대금을 휘두르는 3연타이고, 구르기는 짧은 무적이며, 스킬 "받아넘기기"를 익히면 구르기 초반에 맞을 뻔한 공격이 반격 기회가 된다. 타격과 받아넘기기는 신명을 채우고, 신명이 100이면 처용무로 6초간 무적이 된다. 부적(화염·결박·수호·파동)은 소리(기력)를 쓰는 보조 수단이다. 요괴는 HP 0이 되어도 죽지 않고 쓰러진다(→ `purification.md`). 이 시스템의 HP 감소는 "정화 대상을 만드는 일"이다.

## Player Fantasy

부수는 대신 풀어주는 사람이 되기 위해, 먼저 요괴 앞에서 흔들리지 않는 사람이 된다. 구르기로 공격 사이를 스쳐 지나가고(춤의 덧배기), 아슬아슬하게 받아넘기면 시간이 느려지며 다음 한 번이 두 배로 들어간다. 신명이 차오르면 처용무가 시작된다 — 6초 동안 아무도 처용을 건드리지 못하고, 둘레의 요괴는 탁기가 흔들려 떨어진다. 부적은 "소리"를 먼저 깔아 두는 준비의 감각이다. 리듬 게임이 아니다(기획안 §6 설계 원칙: 리듬 판정 없음, 장단은 스킬 "장단맞춤" 한 곳뿐).

## Detailed Rules

### Core Rules

**입력과 상태** (`player.gd:_physics_process`)

1. 입력 액션: `attack`(베기), `roll`, `talisman`, `swap`, `dance`, `song`, 이동 4방향. 대사·컷신 중(`locked`)에는 이동 입력이 0이고 모든 액션 입력이 무시된다.
2. 상태: `move`, `attack`, `charge`(강 베기 충전), `slash`(강 베기 후딜), `roll`, `song`, `dead`. 처용무(`ult_t > 0`)는 상태가 아니라 덮어쓰기로 동작하며 다른 모든 입력보다 우선한다(`_physics_process`에서 `_ult()` 호출 후 `return`).
3. 기절(`stun_t > 0`)이 걸려 있으면 입력 처리 전에 `return`한다(이동·공격·구르기 불가).
4. 이동 속도 `SPEED = 72.0`(`player.gd:SPEED`). 둔화 ×0.5, 연풍 ×1.25, 신명 고조 ×1.2가 곱해진다(`_move`).

**대금 3연타** (`player.gd:COMBO`, `_start_attack`, `_attack`, `_resolve_hit`)

5. `move` 상태에서 `attack`을 누르면 먼저 `interact`(말 걸기/조사)를 호출하고, 무언가 처리되면 공격하지 않는다. 처리되지 않으면 콤보 0타를 시작한다.
6. 조준: 스틱 방향이 있으면 그쪽을 본다. 없으면 70px 이내(`bd = 70.0`) 가장 가까운 `enemy` 그룹 개체를 향한다(터치용 자동 조준).
7. 3타 수치(Lv.1 기준 피해, 시간은 초, 사거리는 px):

| 타 | 피해 | 스윙 시간 | 사거리 | 비고 |
|---|---|---|---|---|
| 1 | 10 | 0.26 | 34 | |
| 2 | 10 | 0.26 | 34 | |
| 3 | 18 | 0.34 | 42 | 찌르기(`thrust`): 스윙 30~55% 구간 앞으로 110 속도 돌진, 강타(heavy) |

8. 판정은 스윙 진행도 `k = t / 스윙시간`이 0.4를 넘는 순간 1회 일어난다(`hit_done`). 판정 범위: 처용 위치+(0,−14)에서 적 위치+(0,−10)까지 거리 ≤ 사거리, 그리고 바라보는 방향과의 각도 차 ≤ 1.3rad(≈74.5°). 거리 10px 이내 적은 각도를 보지 않는다. 검무 스킬이면 3타는 각도 제한이 없고 사거리 +6.
9. 이어 치기: 스윙 중 `attack`을 다시 누르면 `queued`가 켜지고(시점 제한 없음), 스윙이 끝날 때 `queued`이고 다음 타가 있으면 바로 다음 타로 이어진다. 누르지 않으면 `_end_attack`으로 `combo = 0`이 되어 다음 입력은 다시 1타부터다. 연타 사이에 시간 창(콤보 타이머)은 없다.
10. 한 번의 판정은 범위 안의 모든 `enemy` 그룹 개체를 맞힌다(`take_hit` 보유자만). 쓰러진 요괴는 `downed` 그룹이라 맞지 않는다.
11. 3타 또는 받아넘기기 보너스가 켜진 타는 `heavy = true`로 `take_hit`을 호출한다. 일반 요괴 넉백은 heavy 220 / 일반 130, 보스는 60 / 30. 강 베기는 `take_hit(dmg, dir, true, false, true, t)`로 `charged`(장갑 무시)·`charge_t`(넉백 280→320, 보스 75→90)를 넘긴다(`enemy.gd:take_hit`, `boss.gd:take_hit` — 두 클래스는 같은 시그니처). heavy는 요괴가 `strike` 중일 때도 피격 경직(`hurt`)을 강제한다.
12. `take_hit`을 호출한 대상 1체당 신명 +2.5(`SIN_PER_HIT`), 불꽃(`_spark`)이 튄다. 한 스윙이 여러 체를 맞히면 그 수만큼 오른다. 피해가 실제로 들어갔는지는 보지 않는다 — 복제체를 맞혀 연기가 되거나 저승 파수꾼의 정면 방어에 막혀도 +2.5다. (변장 상태 `wait`의 역신도 `enemy` 그룹이고 `take_hit`이 즉시 return하는데 신명은 오를 수 있다 — 컷신 중 실제로 칠 수 있는지는 불확실.)
13. 스윙 중 피격되면 `hurt()`가 `_end_attack()`을 불러 콤보가 끊긴다.

**강 베기(차징)** (`player.gd:_update_charge_hold`, `_charge`, `_release_charge`, `_slash`) — 베기 길게 누르기 (D2)

13a. 베기를 누르면 지금처럼 즉시 1타가 나간다(말 걸기에 쓰인 눌림은 공격도 충전도 없음). 스윙이 끝나도 버튼이 계속 눌려 있으면 눌림 시점부터 `CHARGE_ENTER = 0.45`초에 `charge` 상태로 들어간다(0.45초 전에 떼면 아무 일 없음). 충전 중 이동 불가(스틱으로 방향만), 발치 링·버튼 링 게이지, 소리 소모 없음.
13b. 손을 떼면 충전 `c < CHARGE_MIN(0.35)`는 조용히 취소(후딜 없음), `c ≥ 0.35`면 발동, `c ≥ CHARGE_FULL(0.90)`이면 만충(번쩍임·햅틱), `c = CHARGE_MAX(2.0)`이면 자동 발동. 발동 후 `slash` 후딜 0.35초(구르기로 취소). 스틱이 없으면 발동 시점에 80px 자동 조준.
13c. 충전 중 실제 피해·기절·끌림·컷신(`locked`)이면 끊긴다. 수호부로 막은 피격·피격 유예 중 피격은 끊지 않는다. 피해는 장갑 무시, 신명 +5/체(Formulas).

**구르기** (`player.gd:_start_roll`, `_roll`)

14. `roll`은 `state != "roll"`이면 베기·처용가 중에도 취소하고 시작된다(후딜 캔슬). 단 **구르기 잠금**: 구르기가 끝나면 `ROLL_LOCK = 0.25`초 동안 새 구르기를 시작할 수 없다. 입력이 잠금 끝 `ROLL_BUFFER = 0.10`초 안이면 선입력으로 저장돼 잠금이 풀리자마자 실행되고, 그보다 이르면 버려진다. 학의 질주(`hak`)의 연속 구르기는 잠금을 무시한다. 충전 중(`charge`)에는 충전 `c < 0.35`일 때만 구르기가 가능(충전 취소)하고 `c ≥ 0.35`면 입력이 무시된다. 시계는 게임 시간(delta 감소)이다. 연속 구르기의 무적 비율은 0.32/0.57 = 56%.
15. 구르기 `ROLL_TIME = 0.32`초 동안 `invuln = true`(전 구간 무적). 방향은 스틱 방향, 없으면 바라보는 방향. 속도 `ROLL_SPEED = 200.0`에서 진행도 k에 따라 `(1 − 0.6k)`로 감속한다. 끌림(`pull_t`)은 구르기 시작 시 0으로 해제된다. 구르는 동안 `stun()`·`slow()`는 무시된다.
16. 구르기가 끝나면 연풍 스킬 시 `haste_t = 2.0`(이동 ×1.25), 구르기 종료 시각을 `_last_roll_end`에 저장하고(학의 질주 연계용) `_roll_lock_t = ROLL_LOCK`을 건다.
17. 학의 질주(스킬 `hak`): 직전 구르기 종료 후 0.3초 안에 다시 `roll`을 누르거나, 구르는 중 0.1초 경과 후 한 번 더 누르면 돌진 구르기(속도 ×2)가 된다. 돌진 후에는 `_last_roll_end`가 −10으로 되어 연속 돌진은 불가.

**받아넘기기** (`player.gd:hurt`, `_parry`) — 스킬 `batanum`(춤 1단, 수련 1점) 전제

18. `hurt(dmg, dir, melee, kind)`가 `invuln` 중에 호출되고, 상태가 `roll`이며, **`melee == true`**(요괴의 근접 접촉 타격·역신 기침 숨결·펄스)이고, 구르기 경과 `t ≤ 창`이면 `_parry()`가 실행된다. 창 = `PARRY_WINDOW = 0.15`초(스킬 `batanum`="되받아치기"면 `PARRY_WINDOW_SKILL = 0.22`). **스킬 없이도 기본 개방**(D1). 투사체·충격파·독기(안개 틱)·장판은 `melee=false`라 받아넘기기가 일어나지 않고 구르기 무적만 작동한다.
19. `_parry()`는 쿨다운 0.3초(`_parry_cd`). 효과: `parry_bonus = true`(다음 타 ×2, 강 베기는 ×1.5), 신명 +15, **소리 +8**, 연속 카운트 +1(10초), 시간 배속 0.35를 0.35초(실시간), "받아넘기기" 텍스트·흰 고리·햅틱. `batanum`이면 추가로 정면(구르기 방향 내적 > 0) 80px 안 요괴(보스 제외)를 피해 0 heavy 넉백으로 밀치고 `_interrupt()`로 예고·타격을 끊는다.
20. `parry_bonus`는 다음 `_resolve_hit`에서 소비된다(맞힌 대상이 없어도 소비). 소비 전에는 시간 제한 없이 유지된다.
21. 연속 3회(마지막 받아넘기기로부터 10초 이내 누적)면 신명 고조 5초(`height_t`): 이동 ×1.2, 스윙 시간 ÷1.3. 카운트는 0으로 초기화된다.

**신명과 처용무** (`player.gd:add_sin`, `dance`, `_ult`)

22. 신명 `shinmyeong`은 0~100(`add_sin`에서 클램프). 오르는 경로: 베기 적중 +2.5/체, **강 베기 적중 +5/체**, 받아넘기기 +15. **피해를 입으면 −12**(`hurt()`가 실제 피해 단계에서 `dmg > 0`일 때, 0 하한; 수호부·무적·유예·튜토리얼 gentle 피격은 감점 없음). 부적·음파·처용무 타격은 신명을 올리지 않는다.
23. `can_dance() = 신명 ≥ 100 and 피리(flute 플래그)를 가짐`. `dance` 입력은 상태가 `move`/`attack`/`charge`/`slash`일 때 받는다.
24. 처용무 시작: 신명 0, 스킬 `sinmyeong`의 폭발 재사용 가능(`_burst_ready = true`), `ult_t = ULT_TIME = 6.0`, "처용무!" 토스트, 오방색 파문 5개. 스킬 `cheonji`면 시작 즉시 화면(480×270) 안 모든 `enemy`에 heavy 피해 — 보스(`PlagueGod`) 12, 그 외 40.
25. 처용무 동안: `hurt()`는 즉시 무시(완전 무적), 이동 속도 60, 베기·구르기·부적·처용가 불가. 0.2초마다 70px 이내 모든 `enemy`에 `take_hit(int(round(30 × (보스면 0.12) × strikes)), 방향, false, quiet=true)`. `strikes`는 스킬 `obang`이면 2, 아니면 1. 이 피해는 `attack_mult`(레벨 보정)를 곱하지 않는다. `quiet`는 소리·경직만 끄고 `dir`(처용→적 방향)은 그대로 넘기므로 틱마다 일반 요괴는 130, 보스는 30만큼 넉백이 들어간다(`enemy.gd:take_hit`, `boss.gd:take_hit`; 장승은 밀리지 않음).
26. 신명폭발(스킬 `sinmyeong`): 신명이 100이 되는 순간 한 번(`_burst_ready`) 90px 이내 `enemy`에 heavy 30 피해, 고리 연출. 처용무는 그대로 쓸 수 있다. 처용무를 쓰면 `_burst_ready`가 다시 켜진다.

**부적** (`player.gd:_talisman`, `swap_talisman`, `fx/talisman_zone.gd`)

## Formulas

### 베기 피해

```
mult   = attack_mult
         × (1.3  if 3타 and rhythm ≥ 2)          # 장단맞춤
         × (2.0  if parry_bonus)                  # 받아넘기기 일격
         × (1.2 if 대상.bind_t > 0 | 1.4 if gyeolbak2)   # 결박된 적 (_bind_mult)
dmg    = int(round(COMBO[n].dmg × mult))
적 실피해 = ceil(dmg × 상태계수)                    # enemy.gd:take_hit — 베기·부적·음파·처용무 등 모든 출처에 적용
상태계수 = STAGGER_MULT.get(kind, 1.5) (stagger, 장갑 해제) | charged ? 1.0 : ARMOR[kind] (장승 0.4·마마귀신 0.6) | 1.0
        # charged = 강 베기·처용무(장갑 무시). 보스는 ×exposure(열림 1.5·시전 노출 1.25)
정면 방어: 저승 파수꾼이 strike/stagger가 아니고 방패 방향이 처용을 향하면 dir가 0이 아닌 모든 피해가 0 (화염·결박은 dir=0이라 막히지 않음)
```

| Variable | Type | Range | Source | Description |
|---|---|---|---|---|
| attack_mult | float | 1.0 ~ 2.45 | `game.gd:attack_mult` = 1 + (lv−1)×0.05, lv 1~30 | 레벨 공격 배율 |
| COMBO[n].dmg | int | 10 / 10 / 18 | `player.gd:COMBO` | 타별 기본 피해 |
| rhythm | int | 0 ~ | `player.gd:_physics_process` | 스윙 55% 이후 이어 친 횟수(스킬 `jangdan` 필요) |
| parry_bonus | bool | | `player.gd:_parry` | 받아넘기기 후 다음 타 |
| 상태계수 | float | 0.4 ~ 2.0 | `enemy.gd:take_hit` | 장승 외에는 stagger일 때만 1.5 |

**계산 예시 (Lv.1, 스킬 없음)**: 1·2·3타 = 10 / 10 / 18. 갯귀(HP 44, `enemy.gd:KINDS.sea`)는 모두 적중해도 한 콤보 38로는 안 쓰러지고 두 번째 콤보 1타(누적 48)에 쓰러진다. 역병 들개(HP 30)는 콤보 3타째(10+10+18=38)에 쓰러진다.
**계산 예시 (Lv.5, attack_mult 1.2)**: 12 / 12 / `round(18×1.2)=22`. 장단맞춤 3타 = `round(18×1.2×1.3)=28`. 받아넘기기 후 3타 = `round(18×1.2×2)=43`. 둘 다면 `round(18×1.2×2.6)=56`.
**다른 출처 예**: 장승(평시)에게 화염 틱 `ceil(5×0.4)=2`, 처용무 틱 `ceil(30×0.4)=12`; stagger 중인 일반 요괴에게 처용무 틱 `ceil(30×1.5)=45`.
**기대 범위**: 3타 피해 18~44(스킬 보너스 제외 Lv.1~30). 부동소수 경계(예: 10×1.45)는 코드 미확인 — 이 문서 예시는 경계를 피했다.

### 강 베기 피해

```
t    = clamp((c − 0.35) / (0.90 − 0.35), 0, 1)
dmg  = round(18 × (1.3 + 1.2·t) × attack_mult × (1.5 if parry_bonus) × bind_mult)
reach = 44 + 8t,  arc = 1.5 + 0.2t,  knock = lerp(280, 320, t) 일반 / lerp(75, 90, t) 보스,  신명 +5/체
```

예: Lv.1 만충 45(마마귀신 HP 70에 장갑 무시 45 — 하네스 확인), Lv.1 최소 충전 23~25, Lv.3 만충 50, 열림 중 보스 `ceil(50×1.5)=75`. 소리 소모 0. 값은 전부 `combat_tuning.gd`.

### 신명 충전

```
shinmyeong' = clamp(shinmyeong + 2.5 × (한 스윙에 맞은 체 수)   # 베기 적중
                                  + 5 × (강 베기에 맞은 체 수)
                                  + 15 × (받아넘기기 횟수)
                                  − 12 × (피해를 입은 횟수), 0, 100)
```

| Variable | Type | Range | Source | Description |
|---|---|---|---|---|
| SIN_PER_HIT | float | 2.5 | `player.gd:SIN_PER_HIT` | 적중 1체당 |
| SIN_PER_PARRY | float | 15.0 | `player.gd:SIN_PER_PARRY` | 받아넘기기 1회 |

**예시**: 단일 대상만 맞히면 40타 = 100. 받아넘기기만으로는 7회(15×7=105→100). **기대 범위**: 0 ~ 100 (상한 클램프).

### 구르기 이동 거리

```
거리 = ∫₀^0.32 200 × S × D × (1 − 0.6·t/0.32) dt = 200 × S × D × 0.32 × 0.7
S = 1.3 (나비춤) | 1.0,   D = 2.0 (돌진) | 1.0
```

**예시**: 기본 44.8px, 나비춤 58.2px, 돌진 89.6px, 나비춤+돌진 116.5px (모두 이 문서의 계산값 — 실측 아님, 지형 충돌 미반영). 출처 상수: `ROLL_SPEED`, `ROLL_TIME`, `_roll`. 세로 이동은 `_slide`가 `1−(1−depth_k)×0.4`를 더 곱한다(`player.gd:_slide`; K=0.75인 레벨이면 ×0.9). 위 거리는 가로 기준.

### 처용무 피해

```
틱 피해 = int(round(30 × (0.12 if 보스 else 1.0) × strikes))      # 0.2초마다, 70px
틱 수   ≈ ULT_TIME / 0.2 = 30  (첫 틱은 즉시)
```

**예시**: 일반 요괴 틱 30 (obang 60). 보스 틱 `round(3.6)=4` (obang `round(7.2)=7`), 한 번 추면 30틱 ≈ 120(obang 210) — 역신 HP 480(`boss.gd:MAX_HP`) 대비 25% / 44%. 틱 수 30은 계산 추정(프레임 의존, 코드 미실측)이며 상한이다: 틱마다 130 넉백이 들어가 요괴가 70px 밖으로 밀리면 적중 틱이 줄 수 있다(미실행 — 불확실).

### 부적 지속 피해

```
화염 DPS = 5 / 0.3 ≈ 16.7   (틱 간격 0.3초, 지속 3.0초 → 약 10틱 = 50, 화염부·진 5.0초 → 약 17틱 = 85)
결박 DPS = 2 / 0.5 = 4.0
```

피해는 `attack_mult`를 곱하지 않는다(`talisman_zone.gd:_physics_process`). 틱 수는 계산 추정이며 마지막 틱의 경계 처리는 코드 미확인.

### 소리(기력) 수지

```
ki' = min(100, ki + 4.0·Δt − 부적 비용 + 8·정화(normal) + 20·정화(elite) + 8·받아넘기기 + 10·수호환급 + 30·2페이즈 전환) (+5 per 피격, 심해의 인내) (+50 구기자환)
정화 체력 = floor(max_hp × 0.04 | 0.11), 한풀이 성립 시 max_hp × 0.15
```

**예시**: 화염 25를 쓰면 소리가 100 → 75, 재생만으로는 6.3초에 다시 25 확보(25/4.0). 비용: 화염 25 / 결박 30 / 수호 20 / 파동 20.

## 코드 미확인

- 키·터치 입력 매핑, 버튼 크기·배치(`project.godot`, `hud.gd`) — 이 문서는 액션 이름까지만 확인.
- 효과음 볼륨·믹싱, 히트스톱·화면 흔들림 같은 타격감 연출: `player.gd`에는 히트스톱/카메라 흔들림 코드가 없다. 다른 파일(`level.gd`, `hud.gd`)은 이 문서 범위에서 확인하지 않았다.
- 요괴 17종 기믹의 세부, 요괴 → 처용 피해 균형(`enemy.gd:KINDS`의 `dmg`는 읽었으나 이 문서의 대상이 아님), 보스 패턴 피해량(`boss.gd` 일부만 확인).
- 입력 지연·프레임 예산·실기기 타격감(실기기 테스트 PLATFORM.DEVICE 미구현).
- 처용무 틱 수(30)와 화염 틱 수의 경계 처리: 프레임 의존으로 코드만으로 확정 불가.
- 부동소수 경계에서의 `round` 결과(예: 10×1.45).
- 부적 사거리 판정 중 `bind_t`가 없는 개체(`"bind_t" in e` 검사)의 존재 여부 — 현재 요괴·보스 모두 필드가 있어 영향 없음으로 보이나 전수 확인 안 함.
- 세이브/로드가 전투 상태(신명·쿨다운)를 저장하는지: `game.gd:save`는 신명·소리를 저장하지 않는다(저장 키 목록으로 확인) — 의도는 미확인.
