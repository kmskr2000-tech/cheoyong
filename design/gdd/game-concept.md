## Elevator Pitch

> 동해 용왕의 아들이 신라의 비밀 어사가 되어, 노래와 춤으로 요괴를 죽이지 않고 정화하며 역병의 근원을 추적하는 모바일 가로 화면 탑다운 액션 RPG.

## Core Identity

| Aspect | Detail |
| ---- | ---- |
| **Genre** | 탑다운 실시간 액션 RPG (웨이워드 소울즈식 전투 + 위쳐식 의뢰·준비 루프) |
| **Platform** | 모바일 웹(GitHub Pages) 우선, Android 후보 |
| **Target Audience** | 한국 설화·다크 판타지·도트 액션을 좋아하는 모바일 플레이어. 세션 10~20분 |
| **Player Count** | 싱글 |
| **Session Length** | 1장 전체 40~60분 목표(기획안 §12.1). 한 판 길이는 **미확정** — 체크포인트 단위 10~20분은 설계 가정이고 근거 문서 없음(성공 기준은 "세션 30분에서 30fps", 기획안 §13). 사용자 결정 대기 |
| **Monetization** | **미확정** — 현재 계획에 과금 요소가 없고(웹 무료 배포, GitHub Pages) 기획안에도 수익 모델 항목이 없다. 사용자 결정 대기 |
| **Estimated Scope** | 중간. 5챕터 완결, 총 약 5~7시간 (기획안 §12.1 제안, 확인 필요) |
| **Comparable Titles** | Wayward Souls(전투), The Witcher 3(의뢰·준비 루프), Sea of Stars·Octopath(화풍) |

## Core Fantasy

이름 없는 어사가 되어, 부수는 대신 **풀어준다**. 노래와 춤으로 한(恨)을 걷어내면 괴물이 원래 모습으로 돌아가고, 그 한풀이가 이야기가 된다.

## Unique Hook

"웨이워드 소울즈식 전투, **그리고** 쓰러뜨린 요괴를 죽이지 않고 노래로 정화한다." 정화가 곧 보상 구조(정기·덕망·한풀이 1.5배)이자 이야기의 주제다.

## Game Pillars

| # | Pillar | 막는 것 |
|---|---|---|
| 1 | 정화, 처치가 아니다 | 학살 보상, 시체 전리품 |
| 2 | 노래가 무기다 (처용가 1~5절) | 말 많은 주인공, 리듬 게임화 |
| 3 | 손가락으로 배운다 (글 없는 튜토리얼, 빛나는 버튼 하나) | 텍스트 튜토리얼, 키보드 전제 UI |
| 4 | 신라, 그러나 귀신이 보이는 (조선 요소 금지) | 갓·도포 외형, 사극 클리셰 |

## Core Loop

의뢰 확인 → 탐험(용패 길잡이) → 전투·정화 → 보상(정기·덕망·엽전·재료) → 준비(제작·퇴치향·강화·수련) → 귀환·보고 → 다음 의뢰.

## Player Goal & Fail State

- 목표: 5장에 걸쳐 처용가 5절을 완성하고 역신왕의 경계 붕괴를 봉인한다.
- 실패: 영구 사망 없음. 사망 시 던전 입구(보스방이면 다락)에서 재시작.

## Anti-Pillars (이 게임이 아닌 것)

기둥별 "막는 것" 열이 곧 Anti-Pillar다: 학살 보상·시체 전리품 / 말 많은 주인공·리듬 게임화 / 텍스트 튜토리얼·키보드 전제 UI / 갓·도포·사극 클리셰.

## Player Experience (MDA 요약)

- **Aesthetics**: 도전(실시간 회피·받아넘기기), 서사(역병의 근원 추적), 발견(요괴 도감·설화), 정서(한을 풀어주는 카타르시스).
- **Dynamics**: 쓰러뜨린 요괴를 모아 한 번에 노래한다(`purification.md`), 구르기로 공격을 스쳐 신명을 채워 처용무로 넘어간다(`combat-core.md`), 구역을 전부 정화해 한풀이 보너스(1.5배)를 노린다.
- **Mechanics**: 전투 코어(#5)·정화(#6)·성장(#13) — `systems-index.md`.
- **Player Type**: 탐험가·성취가 중심(도감 수집, 스킬 빌드 선택). 근거는 기획안 §5·`growth-system.md`; 이 항은 설계 해석이며 플레이테스트로 검증되지 않았다.

## Target Player Profile

한국 설화·다크 판타지·도트 액션을 좋아하는 모바일 플레이어(위 Core Identity). 폰 가로 화면, 터치 조작, 짧은 구간 단위 플레이. 실제 타깃 조사는 없다.

## Inspiration and References

Wayward Souls(전투), The Witcher 3(의뢰·준비 루프), Sea of Stars·Octopath(화풍), 삼국유사 처용랑 망해사 설화·한국 구비 설화(세계관). 복식·고유명사 규칙은 기획안 §14.

## Technical Considerations

Godot 4.4 + GDScript, GL Compatibility, 480×270 정수 배율 픽셀 퍼펙트, 코드 루트 `src/`(ADR-0001). 모바일 웹(스레드 없음) 빌드를 GitHub Pages(`gh-pages`)로 배포하는 경로가 ADR-0002로 정해졌다. 아트는 코드 생성 + 승인된 외부 세트의 정규화 임포트.

## Risks and Open Questions (요약)

위험(기획안 §13): 사용자가 보는 빌드와 개발 빌드의 불일치, Godot에 전투 회귀 테스트 부재, 모바일 성능(HD-2D 후처리, 미측정), 범위 팽창(5~7시간 재산정으로 완화), 아트 파이프라인 단일 의존. 성공 기준: ① 폰에서 1장을 막힘 없이 끝낸다 ② 5장 완결 플레이스루 ③ 1장 보스 첫 도전 평균 사망 1~3회(실측 후 확정) ④ 콘솔 오류 0, 세션 30분 30fps 이상.

## Scope Tiers

`systems-index.md`의 Priority Tiers(MVP → Vertical Slice → Alpha → Full Vision)를 따른다. 예산이 줄면 Full Vision(2~5장 폴리시·해상전)부터 줄이고 5장 완결성은 지킨다 — 이 줄이는 순서는 설계 제안이다.

## Out of Scope (확정)

멀티플레이, 보이스(기획안 §11 "보이스 없음"), 패스트트래블(4장 이전; 4장 용궁 물길 이후 도입, 기획안 §3), 과금 요소와 PC·콘솔 포팅은 현재 계획에 없다(근거 문서는 없으며 Monetization 결정과 함께 확인).

## MVP Definition (MVP / Vertical Slice)

**Vertical Slice = 챕터 1 (구현됨, 폰 검증 대기).** 인트로 → 백사장 튜토리얼 → 경주 일상 → 폐가 → 역신 → 임명 → 1절 완성. 완료 기준은 `production/milestones/m1-chapter1-validated.md`.
