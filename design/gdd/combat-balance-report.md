## 0. 한 줄 결론

1. **지배 전략이 있다: "다가가서 베기 버튼 연타".** 1장 요괴 7종 전부에서 피해 0, 가장 빠른 축에 든다. 예고를 읽고 구르기·받아넘기기를 하는 쪽이 오히려 **더 느리고 더 많이 맞는다.** → "읽으면 보상" 설계(Pillar 3)가 현재 작동하지 않는다.
2. 원인은 수치가 아니라 **구조 1줄**이다: 가벼운 타격이 적의 예고(tell)를 항상 끊는다(`enemy.gd take_hit`: `elif state != "strike" or heavy: state = "hurt"`). 연타 간격(0.26~0.34s)이 경직(0.25s)보다 짧아 경직 락이 된다. 상수 변경만으로는 못 고치고, **상수 1개(TELL_CANCEL_FRAC)를 신설**해야 한다.
3. 두 번째 원인은 **요괴가 너무 빨리 죽는다**: 플레이어 3연타 한 사이클(Lv2 39 / Lv3 42 피해, 0.86초)이 요괴 HP 30~44를 거의 한 번에 깎는다. 요괴가 공격할 시간 자체가 없다.
4. 구르기 연타는 지배 전략이 **아니다**(잠금 0.25초 덕분). 강 베기 단독도 아니다(빠른 적에게 진다). 이 둘은 의도대로 작동 중 → 건드리지 말 것.
5. 역신은 해석 모델상 **HP 480이 DPS 대비 4~8배 짧다**(숙련 9~22초 vs GDD 목표 90~150초). GDD 내부 모순이므로 디렉터 결정이 필요하다(§5).

## 2. 전략성 감사

### 2.1 지배 전략 판정

| 후보 | 판정 | 근거 |
|---|---|---|
| **탭 연타(접근 후 연타)** | **지배 — 수정 필요** | 단독 7종 전부 피해 0(마지막 줄 제외 평균 2.7초), 무리에서도 읽기보다 처치가 빠르고 피해는 비슷하거나 근소하게 큼. 읽기 정책은 단독 평균 3.1초/2.0 HP로 **탭(2.7초/0 HP)보다 느리고 더 맞는다.** |
| 구르기 연타 | 지배 아님 (OK) | 무리에서 피해 10.7~27, 읽기·탭보다 높다. 잠금 0.25s가 의도대로 억제. |
| 강 베기만 | 지배 아님 (OK) | 빠른 적(들개·물귀신·처녀귀신)에게 40초 내 못 이기고 피격 12~18회. 느린 적(역귀·갯귀·달걀·마마)에는 가능하나 탭보다 느림. |
| 수호부 선행 | 준지배 (주의) | 단독·무리 거의 전부 피해 0~2.7. 소리 20이 필요하지만 재생 4.0/s라 한 교전마다 공짜에 가깝다. |
| 결박부 선행 | 효율 최상 (설계 의도 범위) | 처치시간 −40~50%(1.5 vs 2.7), 마마 3.4 vs 5.5. 이동 ×0.35가 곧 "공격 불가"라 사실상 무력화 도구. |
| 받아넘기기(읽기) | 무보상 — 수정 필요 | 보상(신명 +15, 소리 +8, 다음 타 ×2)이 처치 속도를 못 올린다: 들개는 읽기·탭 모두 1.1초에 죽는다. 읽을 이유가 없다. |

### 2.2 "아무 선택이나 같은" 구도

- **개운포~폐가1의 단독 요괴 전부**: 탭·구르기·읽기·수호부·결박 어느 쪽이든 승리, 피해 0~8. 선택이 결과를 못 가른다 → 단독 교전에는 "선택"이 없다.
- 무리 교전만 정책이 갈린다(수호부 0 / 결박 4.7~8 / 탭 8~16 / 구르기 10~27). 전략성은 **무리에서만** 살아 있다.

### 2.3 경직 락의 메커니즘 (코드 근거)

`enemy.gd:take_hit` — `state == "tell"` 중 가벼운 타격은 `state = "hurt"`(0.25초)로 바뀌며 예고가 끊긴다. 콤보 3타 간격은 0.26 / 0.26 / 0.34초이고 `cd`는 `hurt` 중에도 줄지만 다시 `_begin_tell`이 필요하다. 결과: 접근해서 연타를 시작하면 적은 **예고 → 경직 → 예고 → 경직**만 반복하다 쓰러진다. 강 베기·파동부가 "예고를 끊는 열쇠"라는 GDD §1의 서술은 사실상 무의미(가벼운 타격도 끊음).

## 3. 튜닝 제안 (우선순위 순, 프로그래밍팀 적용용)

### P0 — 오늘 적용 (경직 락 해체)

| # | 상수 | 현재 | 제안 | 근거 / 효과 |
|---|---|---|---|---|
| 1 | `CT.TELL_CANCEL_FRAC` (신규) | 암묵 1.0 (예고 어느 시점이든 가벼운 타격이 끊음) | **0.5** | 가벼운 타격은 예고 앞쪽 50%만 끊는다. 뒤쪽 50%는 "굳은 예고": 강 베기·3타째(heavy)·받아넘기기 일격·파동부만 끊음. 측정(`raw/ttk2_tcf0.5.txt`): 단독 평균 피해 탭 0 → **4.3**, 읽기 2.0 → 읽기가 더 안전해짐. 무리: 탭 16.7 vs 읽기 10.0. (TCF=0.0도 비슷: 탭 5.8) → 0.5 채택(완전 무끊김보다 손맛 유지) |

`elif state == "tell" and not heavy and st >= float(cfg["tell"]) * CT.TELL_CANCEL_FRAC: pass` 추가.

## 5. 역신 측정 (진행 중)

- 봇 측정 `raw/boss.txt`: 정책 7종(탭·읽기 miss 0/0.3/0.5/0.7·읽기+충전) × 6회. 사망은 가상 계산(누적 피해 ≥ 112, 재도전은 CS-12 규칙으로 HP·페이즈 초기화). 도착 시 이 절을 갱신한다.
- 우선 확정되는 것: **목표(1장 사망 중앙 3 / p90 ≤ 7 / 역신 평균 1.8)** 와 실제의 격차는, 봇 miss 비율 중 어느 값에서 평균 1.8회가 나오는지를 "목표가 가정하는 플레이어 숙련도"로 역산해 적는다.
