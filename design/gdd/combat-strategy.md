## Overview

**문제.** 지금의 전투는 "3연타 → 구르기 → 가끔 부적"이다. 요괴 종류가 달라도 정답이 같다(전부 3연타 + 구르기). 구르기는 0.32초 전체가 무적이고 연속으로 쓸 수 있으며(쿨다운·자원 없음) 받아넘기기도 구르기 시작 0.25초(78%)에 자동으로 걸리므로, 구르기를 계속 누르면 근접 공격은 사실상 맞지 않는다. 부적은 소리가 초당 6씩 차올라(화염 25 = 4.2초) 비용이 느껴지지 않는다. 수호부는 독기 틱 한 번에 벗겨지고 기절·끌림·둔화는 못 막는다. 보스 패턴은 읽을 수는 있지만 "읽어서 얻는 것"(공격 기회)이 따로 없다.

**목표.** "무엇을 언제 쓸지"가 매 교전마다 달라지게 한다. 설계 원칙 5개:

1. **적마다 정답이 다르다.** 모든 요괴에게 통하는 만능 행동을 없애고(구르기 연타 억제, 수호부·결박·화염·강 베기·받아넘기기에 각각 "이 적에게는 이게 제일 싸다"가 있다), 같은 행동이 다른 적에게는 손해가 되게 한다.
2. **정답은 비용을 치르고 보상받는다.** 모든 선택은 소리·신명·체력·시간 중 하나를 쓰고 하나를 돌려받는다(→ Detailed Rules §2).
3. **읽으면 열린다.** 예고(telegraph)를 읽고 정답을 내면 적이 "열린다"(후딜 = 1.5배 피해 창). 열린 창을 얼마나 쓰느냐가 숙련이다.
4. **죽이지 않는다.** 어떤 선택지도 "처치"가 아니다. 피해는 요괴를 쓰러뜨릴 뿐이고, 보상·회복은 **정화(처용가)** 에서만 나온다(→ §6).
5. **엄지 두 개로 된다.** 왼 엄지 조이스틱 + 오른 엄지 버튼 하나로 모든 필수 행동이 가능해야 한다. 신규 버튼 없음(→ §5).

## Player Fantasy

춤꾼의 눈이 된다. 들개가 웅크리는 순간 구르기를 눌러 발톱 사이를 빠져나가며 "받아넘기고", 다음 한 번은 두 배로 들어간다. 처녀귀신의 울음 고리가 퍼질 때는 몸을 던져 그 한가운데를 통과한다. 마마귀신이 종기를 뿜는 사이 거리를 좁히고, 후딜에 숨을 모아 대금을 크게 휘두른다 — 그 한 번의 "강 베기"가 단단한 껍질을 깬다. 물귀신의 발목 끌기 앞에서는 수호부를 먼저 얹어 두고 걸어 들어간다. 군집이 몰려오면 결박부를 깔고, 불을 얹고, 쓰러진 것들을 한 번의 노래로 거둔다. 역신 앞에서는 정해진 순서(안개 → 기침 → 졸개 → 기침)를 몸으로 외워, 기침이 지나간 뒤 열린 1.2초에 가장 큰 일격을 넣는다.

이길 때 느끼는 것은 "내가 센 것"이 아니라 "내가 읽은 것"이다. 그리고 마지막은 언제나 노래다 — 쓰러진 것을 베어 넘기는 게 아니라 풀어준다.

#### 받아넘기기 (D1: 기본 개방, 재설계)

현재 규칙은 `hurt()`가 무적 중 호출되고 구르기 `t ≤ 0.25` + 스킬 `batanum`이면 발동한다. 이대로 스킬 조건만 빼면 구르기 78%가 자동 받아넘기기가 되어 신명·×2가 공짜가 된다. 그래서 같이 바꾼다.

- **창 축소**: 구르기 시작 후 **0.15초**(≈9프레임) 안에 "근접 접촉 공격"이 닿으면 발동. 스킬 `batanum`("되받아치기"로 개명, 아래)을 익히면 **0.22초**.
- **대상 제한**: `hurt(dmg, dir, melee)`에 `melee` 플래그를 도입한다. 발동 조건 = `invuln` ∧ 상태 `roll` ∧ `t ≤ 창` ∧ `melee == true` ∧ `_parry_cd == 0`. `melee == true`로 부르는 곳: 요괴의 접촉 타격(`enemy.gd` strike 분기, 저승 파수꾼 찌르기), 역신의 기침 숨결(`boss.gd:_breath`)·펄스(`boss.gd` pulse). `melee == false`(기본): 투사체·충격파·독기·장판·안개 틱. (투사체와 충격파는 이미 `state == "roll"`이면 `hurt()`를 아예 부르지 않으므로 "구르기로 통과"가 정답이고, 안개 틱이 받아넘기기를 일으키던 현재의 의도치 않은 동작이 사라진다.)
- **구르기 잠금 (신규)**: 구르기가 끝나면 **0.25초** 동안 새 구르기를 시작할 수 없다(베기·부적·노래는 가능). 구르기 입력은 잠금 끝 0.10초 전부터 **선입력**으로 저장되어 잠금이 끝나자마자 실행된다(터치 지연 완충). 학의 질주(`hak`)의 연속 구르기는 잠금을 무시한다(스킬 보상). 효과: 연속 구르기의 무적 비율 100% → 0.32/0.57 = **56%**. 이것이 "구르기 연타가 정답"을 끝낸다.
- **보상**: 신명 +15(현재와 같음), 다음 타 ×2(현재와 같음), **소리 +8(신규)**, 시간 배속 0.35 × 0.35초(현재와 같음), 쿨다운 0.3초(현재와 같음). 받아넘기기 3연속(10초 이내) 신명 고조 5초(현재와 같음).
- **스킬 `batanum`**: 이름 "받아넘기기" → **"되받아치기"** 로 바꾸고 id는 유지한다(세이브 호환·선수 관계 유지·수련 점수 환불 불필요). 효과: ① 창 0.15 → 0.22초 ② 받아넘기기 성공 시 정면 80px 안 모든 `enemy`를 밀쳐 낸다(피해 0, heavy 넉백 + 상대의 예고/타격 중단). 춤 1단이 `nabi`·`yeonpung` 2개로 줄지 않는다(`batanum` 슬롯이 유지됨 → 2단 선수 조건 충족 경로 3개 유지).

#### 강 베기 (D2: 차징, 신규)

공격 버튼을 **길게 누르면** 대금을 크게 모아 휘두른다. 소리를 쓰지 않는다. 대가는 시간과 무방비다.

**입력 흐름 (탭 경로는 한 줄도 바꾸지 않는다):**

1. `attack` 눌림 → 지금과 똑같이 1타가 즉시 나간다(상호작용 가능하면 말 걸기 우선 — 이 경우 이후 차징도 일어나지 않는다).
2. 1타가 끝났는데 버튼이 **계속 눌려 있으면** 대기(`charge_pending`): 상태는 `move`이고 이동·구르기·부적 모두 가능. 누른 시간이 눌림 시점부터 **0.45초**(`CHARGE_ENTER`)에 이르면 `charge` 상태로 진입한다. 0.45초 전에 손을 떼면 아무 일도 없다(느린 탭이 차징으로 오인되지 않게 하는 완충).
3. `charge` 상태: **이동 불가**(방향 전환만 가능 — 스틱으로 조준), 대금을 뒤로 당기는 자세 + 버튼 둘레 게이지 + 캐릭터 발치 링. 충전 시간 `c`는 진입 시 0.
4. **손을 떼면**: `c < 0.35`(`CHARGE_MIN`)면 조용히 취소(후딜 없음, 소리·신명 손실 없음). `c ≥ 0.35`면 강 베기 발동(→ 아래). `c ≥ 0.90`(`CHARGE_FULL`)이면 "만충" 번쩍임 + 진동 + 최대 위력. `c = 2.0`이 되면 자동 발동(손가락이 멈춘 경우의 무한 대기 방지).
5. 발동 후 **후딜 0.35초**(이동 불가, 구르기로 취소 가능).

**위험 (D2 "사용 중 이동 불가 위험"):**
- 충전 중 구르기는 `c < 0.35` 동안만 가능(취소). `c ≥ 0.35`부터는 구르기 입력을 무시한다("힘을 모은 몸은 뜻대로 안 움직인다"). 약속된 위력이 있는 만큼 약속된 위험이다. (터치에서는 공격 엄지를 누르고 있어 구르기도 같은 엄지 몫이므로 자연스러운 제약이다.)
- 충전 중 **피해가 들어가면**(`hurt()`가 피해 단계까지 간 경우) 충전이 끊기고 발동하지 않는다(`_end_attack`). 수호부로 막은 피격·피격 유예 중 피격은 끊지 않는다 → **수호부 + 강 베기**가 정식 콤보(→ §3).
- 충전 중 기절(`stun`)·끌림이면 끊긴다.

**위력:**

| 항목 | 3타(현재) | 강 베기 `c=0.35` | 강 베기 `c≥0.90` |
|---|---|---|---|
| 피해 (Lv.1) | 18 | 23 | 45 |
| 사거리 | 42 | 44 | 52 |
| 판정 각도 | ±1.3rad | ±1.5 | ±1.7rad |
| 넉백 일반 / 보스 | 220 / 60 | 280 / 75 | 320 / 90 |
| 장갑 | 적용 | **무시** | **무시** |
| 예고·시전 중단 | heavy라 `hurt` 강제 | 같음 + 보스 시전 중단(§5) | 같음 |
| 신명 | +2.5/체 | +5/체 | +5/체 |

공식은 §Formulas. 강 베기는 **정화 철학과 충돌하지 않는다**: HP 0이면 똑같이 쓰러짐(`downed`)이며 차징 일격으로 쓰러진 요괴도 노래로만 정화된다. 강 베기가 DPS상 3연타보다 높지 않도록(차징 1.56초에 45 vs 콤보 1.0초에 38) 맞췄다 — 강 베기의 가치는 **DPS가 아니라 장갑 무시·예고 끊기·긴 후딜 창을 한 방에 쓰는 것**이다.

#### 수호부 (D3: 기절·끌림·둔화도 차단, 독기 대응)

현재: 다음 피격 1회(`suho2` 2회)를 무효화하고 10초 뒤 사라진다. 같은 공격의 `stun`/`pull`/`slow`는 `hurt()` 뒤 요괴 코드가 무조건 호출해서 통과한다. 독기 틱(`hurt(dmg, Vector2.ZERO)`)이 수호부를 한 틱에 소모한다.

변경:
- **상태이상 차단**: 수호부가 피격을 막는 순간 `_guard_t = 0.4초`를 건다. `stun()`·`pull()`·`slow()`는 `_guard_t > 0`이면 즉시 return한다(같은 프레임에 이어지는 호출을 모두 덮는다). 또 `slow()`는 구르기 무적(`invuln`) 중에도 무시한다(현재 `slow`·`pull`은 검사 없음 → 구르는 중에도 걸림).
- **독기 틱 무효 (신규)**: `hurt(dmg, dir, melee, kind)`의 `kind == "miasma"`(안개 장판·독기 함정 틱)는 수호부가 켜져 있는 동안 **충전 소모 없이 0 피해로 무시**한다(10초 지속). 호출처: `boss.gd:_poison` 타이머, `vent.gd:77`.
- **파괴 환급 (신규)**: 수호부가 **직접 타격 한 번을 막아 사라질 때** 소리 +10을 돌려준다(비용 20 → 실질 10). 막지 못하고 10초가 지나면 환급 없음 → "불필요한 수호부"는 손해, "정확히 막은 수호부"는 반값.
- `suho2`(진): 충전 2회 + 막은 공격을 음파로 되돌림(현재와 같음), 환급은 마지막 충전이 소모될 때 1회.

### 2. 자원 트레이드오프

체력·소리·신명·시간·쓰러짐 타이머(9초)가 서로 먹고 먹힌다. 아래 표가 이 문서의 "경제"다. **(변경)**은 코드 값이 바뀌는 것이다.

| 자원 | 최대 | 쓰는 곳 | 얻는 곳 | 긴장 |
|---|---|---|---|---|
| **체력** | 100 + 6×(Lv−1) (현재) | 피격 | 레벨업 전회복(현재), **정화 +4(normal)·+12(elite)(신규)**, 구기자환(현재) | 노래(1.1초 무방비)는 체력을 되찾는 유일한 전투 중 수단 → 위험을 감수하고 부르는 이유가 생긴다 |
| **소리** | 100 | 부적(화염 25·결박 30·수호 20·파동 20) | 재생 **초당 4.0 (변경, 현재 6.0)**, 정화 **+8(normal)·+20(elite)(신규)**, 받아넘기기 **+8(신규)**, 수호 환급 **+10(신규)**, 심해의 인내 +5/피격(현재) | 재생만으로는 부적이 6~7초에 하나(화염 6.3초). 정화·받아넘기기를 해야 소리가 풍부해진다 → **싸우는 방식이 부적 빈도를 정한다** |
| **신명** | 100 | 처용무(전부) | 베기 적중 +2.5/체, 강 베기 +5/체(신규), 받아넘기기 +15 | **피해를 입으면 −12 (신규, 하한 0)**. 대충 싸우면 신명이 안 차고, 깔끔하게 싸울수록 처용무가 빨리 온다 |
| **시간** | — | 강 베기 충전(0.8~1.35초), 노래(1.1초), 구르기 잠금(0.25초) | — | 모든 "강한 행동"은 무방비 시간을 산다 |
| **쓰러짐 타이머** | 9.0초/마리 | 방치하면 반피로 일어남 | 노래 중에는 정지 | 쓰러뜨린 뒤 "계속 싸울까 / 지금 부를까"의 압박. 군집은 모아서 한 번에 부르는 게 이득이나 9초 안에 |

**의사결정 예시.**
- 소리 55, 결박(30)을 쓸까 수호(20)를 쓸까 — 군집이 오고 있다면 결박. 물귀신 앞이면 수호.
- 신명 100, 지금 처용무를 쓸까 — 졸개 6마리가 몰렸으면 지금. 보스 2페이즈 전이라면 아껴 둔다(2페이즈 졸개 3마리 + 안개 4개에서 6초 무적이 더 값지다).
- 쓰러진 들개 옆에 역귀가 다가온다 — 지금 불러 소리 +8·체력 +4를 챙길지(역귀에게 맞으면 노래가 끊김), 역귀를 먼저 쓰러뜨리고 한꺼번에 부를지.

### 3. 부적 3종 + 파동부 조합 시너지

1장 시점 현실: 보스 도착 시 레벨 약 3(수련 점수 2점)이라 `padong`(소리 1단 2개 + 점수 1 = 3점)은 **보스 전에 얻기 어렵다**(→ Formulas "1장 성장 예산"). 그래서 시너지 설계는 **3종만으로 완결**되고 파동부는 "후반 가산"이다.

| # | 이름 | 구성 | 규칙 | 효과 |
|---|---|---|---|---|
| S1 | 불길 가두기 | 결박 → 화염 | 결박된 적(`bind_t > 0`)이 화염 틱을 맞으면 ×1.6 | 화염만 쓸 때 DPS 16.7 → 결박 위에서 26.7. 결박(30)+화염(25) = 소리 55에 군집 정리. 이동이 느려져 불에서 못 벗어남 |
| S2 | 보호막 노래 / 보호막 일격 | 수호 → 처용가 또는 강 베기 | 수호부가 켜진 동안 노래·충전은 막아낸 피격으로 끊기지 않는다(현재 노래는 이미 그렇다 — 강 베기에도 같은 규칙) | 수호(20) 켜고 군집 앞에서 1.1초 노래를 부르거나 1.3초 충전. 막으면 환급 +10 |
| S3 | 쓸어 담기 | 처용무/결박 → 처용가 | 처용무 틱(30)·결박 지속 피해로 군집이 한꺼번에 쓰러지면 90px 안에서 노래 한 번에 전원 정화 | 한풀이(구역 전원 정화) 달성의 정석. 정화 소리·체력 회복이 마릿수만큼 한 번에 들어옴 |
| S4 | 묶어 울리기 (`padong`) | 결박 → 파동 | 결박된 적에게 파동부 피해 ×2(6→12), 넉백 ×0.5, 시전 중단 | 묶인 마마귀신·처녀귀신의 시전을 끊고 제자리에 둠. 파동 단독은 밀어내기라 군집을 흩뜨리는 약점이 있는데 결박이 그걸 막음 |

그 외 기존 시너지(스킬): `gyeolbak2`(결박 위 베기 ×1.4), `hwayeom2`(장판 확대), `suho2`(되돌려 치기), `eumpa`(음파 — 원거리 견제, 5×attack_mult, 장갑 적용).

### 4. 적 유형별 정답표

1장 등장 요괴(`levels.gd`: 개운포 튜토리얼 갯귀 / 폐가1 들개·역귀·물귀신·처녀귀신 / 폐가2 역귀·달걀귀신·들개·처녀귀신·마마귀신 / 보스 역신 + 졸개) 기준. "정답"은 가장 적은 자원으로 가장 큰 이득을 얻는 행동, "오답"은 쓸 수는 있으나 손해인 행동이다.

| 요괴 (HP / 예고 / 위협) | 정답 | 차선 | 오답 (손해 이유) | 정답의 이득 |
|---|---|---|---|---|
| **역병 들개** (30 / 0.4초 / 돌진 8) | **받아넘기기** (돌진 접촉) | 구르기로 피하고 후딜 때리기 | 강 베기(충전 1.16초 안에 돌진이 옴), 수호부(8 피해에 20 소리) | 신명 +15·소리 +8·다음 타 ×2. 헛돌진 후 신규 후딜 0.5초(**신규** `_stagger(0.5)`, ×1.5 피해 창)에 3연타 2회 안에 쓰러짐 |
| **역귀 졸개** (40 / 0.5초 / 느림 30, 사거리 22) | **3연타 + 거리 두기** (느려서 맞고 빠지기) | 결박부(군집일 때) | 강 베기(단독 상대엔 과투자), 받아넘기기(모든 접촉이 정답이라 새로울 것 없음) | 느린 적은 시간 싸움. **군집 2마리 이상이면 결박부 + 화염(S1)** |
| **갯귀** (44 / 0.9초 / 내려찍기 12) | **구르기로 피하고 후딜 때리기** (긴 예고 = 안전한 구르기) | 받아넘기기 | 부적 소모 | 내려찍은 뒤 신규 후딜 0.8초(**신규** `_stagger(0.8)`)에 강 베기 반충전도 가능 — 튜토리얼에서 "예고를 보면 구른다 → 후딜에 친다"를 가르침 |
| **물귀신** (44 / 0.7초 / 끌림+둔화, 접근 불가 수중) | **수호부** (피해·끌림·둔화 전부 차단, **D3**) | 구르기(끌림 해제, 피해 1회 감수) | 화염부(사거리 52 밖·화염 58 안의 띠가 좁음), 강 베기(충전 중 끌려와 끊김) | 수호부 20 소리로 접근해 3연타 4번에 쓰러뜨리고, 막으면 +10 환급 |
| **처녀귀신** (40 / 0.9초 / 울음 고리 반지름 84, 기절 1.2초) | **구르기로 고리 통과** (고리가 번지는 0.6초 동안 `roll` 상태면 통과) | 수호부(기절 차단·4 피해 막음), 결박부(거리 유지를 막음) | 강 베기(기절당하면 끊김), 받아넘기기(충격파는 대상 아님 — 구르기 통과로 충분) | 접근 후 3연타 4번. 거리 유지(`keep 66`)가 있으므로 **결박으로 도망을 막으면** 한 번에 닿음 |
| **달걀귀신** (36 / 0.5초 / 은신 후 돌진 10) | **받아넘기기** (예고 시 드러남, 돌진 접촉) | 화염부로 미리 드러내기(`reveal_t 2초`) | 강 베기(보이지 않아 조준 불가), 수호부 | 은신이 풀리는 것은 예고 0.5초 + 근접 34px뿐 — 정확한 받아넘기기가 가장 싸다 |
| **마마귀신 (정예)** (70 / 0.8초 / 종기 3발 부채꼴, 유지 거리 92) | **구르기로 종기 통과 → 접근 → 결박부로 거리 유지를 막고 → 강 베기** (결박은 이동만 늦추므로 충전 1.35초 동안 종기 사선 밖에 선다) | 후딜 1.2초에 3연타 2회(장갑 해제 ×1.5), 파동·음파 견제 | 3연타(장갑 ×0.6: 10→6, 18→11), 화염 틱(5→3), 받아넘기기(종기는 대상 아님) | **신규 장갑**(일반 타 ×0.6, 후딜 중에는 ×1.5, **강 베기·처용무는 장갑 무시**). 결박된 마마귀신(×1.2)에 Lv.3 풀 충전 강 베기 `round(18×2.5×1.10×1.2)=59` = HP 70의 84%. 시전 후 신규 후딜 1.2초(**신규**, ×1.5)에는 3연타 2회로도 처리 |
| **역신 졸개 무리** (보스 소환 2~3마리) | **결박부(군집 중심) + 화염(S1) 또는 처용무** | 3연타 | 개별 처치(졸개 3마리 동시 접촉 30 피해) | S3: 결박 → 쓰러뜨려 한 번에 노래 → 체력·소리 회복 |

**2장 이후 요괴를 위한 일반 원칙** (이 문서의 범위 밖이지만 "만능 정답 금지" 규칙을 이어가기 위한 기준만 적는다):

| 유형 | 요괴 | 정답 방향 |
|---|---|---|

### 5. 역신 (1장 보스) — 읽고 대응하는 구조

**역신 패턴 3종 + 반접근 규칙 1종** (`boss.gd`). 핵심 설계 변경은 "예고를 읽고 정답을 내면 **열린다(open)**"는 구조의 신설이다.

| 패턴 | 현재 (예고 → 공격) | 정답 | 신규 규칙 |
|---|---|---|---|
| **안개 (fog)** | 0.9초 시전 후 플레이어 주변 반경 50 안 3곳(2페이즈 4곳)에 반경 22 독 안개, 4.5초, 0.5초마다 5(역신의 눈물 5→3) | **걸어서 벗어나기** (반경 22는 좁다), 안개 속에서 싸우려면 수호부(독기 `kind` 규칙) | 시전 0.9초 동안 역신은 "시전 노출" — 받는 피해 ×1.25. 안개는 기침의 부채꼴을 가로막는 배치이기도 하므로 안개 → 기침 순서를 지형으로 이용 |
| **기침 (cough)** | 1.0초 부채꼴(±0.5rad ≈ ±28°, 길이 120) 붉은 예고 후 숨결 14 (2페이즈 2연속, 두 번째 예고 0.45초, 속도 ×1.35) | **옆으로 피하기**(부채꼴 밖) 또는 **받아넘기기**(숨결 접촉, 신규로 가능) | **끝난 뒤 열림 1.2초** (2페이즈 0.9초, 2연속은 두 번째 후). 열림 동안 역신은 이동·공격 불가, **받는 피해 ×1.5**. 정답으로 비켜 서 있던 플레이어가 강 베기를 충전해 두었다가 숨결이 끝나는 순간 풀 충전으로 베는 것이 최고 효율 |
| **졸개 소환 (clones)** | 0.8초 시전 → 역귀 2마리(2페이즈 3마리)를 역신 주변 40px에 소환, 각각 chase | **결박부(군집 중심) + 화염, 또는 시전 중 강 베기로 시전 끊기** | 시전 0.8초 동안 "시전 노출" ×1.25. **풀 충전 강 베기가 시전 중인 역신에 맞으면 시전 중단**(소환 취소) + 역신 `stagger` 1.2초. 졸개는 쓰러뜨려 모으고 한 번에 노래(S3) — 보스를 무릎 꿇린 뒤 일괄 정화되는 기존 규칙(`boss.gd:_defeat`)은 유지 |
| **펄스 (pulse)** — 반접근 | 반경 58px에 1.6초 붙어 있으면 0.6초 고리 예고 후 반경 80 충격, 12 피해 | **붙었다 빠지기** 또는 **받아넘기기**(신규 가능) | 펄스 후 열림 1.0초(탈진). 1.6초 규칙은 유지 — 붙어서 때리는 시간 한도를 가르쳐 준다 |

**패턴 순서 (고정 — 학습 가능):** 1페이즈 `안개 → 기침 → 졸개 → 기침` 반복, 2페이즈 `안개 → 기침 → 졸개 → 기침 → 안개 → 졸개`(현재 코드와 같음, 바꾸지 않는다). 순서가 고정이므로 두 번째 도전부터 "다음에 무엇이 오는지" 안다.

**예고 강화 (P1):** 패턴 직전 0.5초 동안 역신 둘레에 색 오라(안개 녹색 / 기침 적색 / 졸개 보라)를 띄워 순서를 눈으로 확인하게 한다. 대사나 글 없이 색만.

**2페이즈 (HP ≤ 50% = 240):**
- 전환 연출 `phase_shift` 1.2초: 역신이 포효(현재 고리 연출), 안개 제거, 소환된 졸개는 유지, 플레이어 **소리 +30**(2페이즈 준비 보상). 이 1.2초 동안 역신은 받는 피해 ×1.5(열림).
- 이동 ×1.35, 대기 간격 1.4 → 1.0초, 안개 4곳, 기침 2연속, 졸개 3마리(모두 현재 값).
- **전략 질문이 바뀐다**: 1페이즈는 "기침 후 열림에 강 베기", 2페이즈는 "열림 0.9초 + 2연속 기침 + 졸개 3마리"로 충전 가능 시간이 줄어든다 → 강 베기를 반충전(0.35~0.6)으로 쓸지, 3연타로 돌릴지, 신명 100으로 처용무를 쓸지(6초 무적 동안 졸개 3마리와 안개를 한 번에 정리하고 역신에 약 120 피해) 고른다.

**보스 피해 모델:** 숨결 14, 펄스 12, 안개 5/0.5초, 졸개 10/타. 플레이어 체력 Lv.3~4 약 112~118 → 숨결 8번 또는 숨결+안개 서성임+졸개 접촉이 겹치면 죽는다.

### 6. 정화 철학 유지

- 어떤 새 규칙도 "처치"를 만들지 않는다. 강 베기·부적·처용무로 HP가 0이 된 요괴는 모두 `downed`(탁기에 덮여 누움)가 되고 보상·회복은 **노래로 정화할 때만** 나온다. 신규 보상(체력 +4/+12, 소리 +8/+20)도 정화 시점에만 지급한다.
- 장갑(마마귀신 ×0.6)은 "더 안 죽는 적"이 아니라 "다른 방법으로 쓰러뜨려야 하는 적"이다. 강 베기는 처치 수단이 아니라 닫힌 껍질을 푸는 열쇠로 설명한다(연출 문구: 쓰러짐 대신 "탁기가 풀렸다" 계열 — 문구는 서사팀).
- 정화 압박: 쓰러짐 타이머 9초(현재)가 "쓰러뜨리고 방치"를 막는다. 신규 정화 회복이 "노래를 불러야 할 이유"를 전투 안에 둔다 — 안 부르면 체력도 소리도 못 얻고 요괴는 반피로 일어난다.
- **한풀이 최소 정화 3 유지 (D4)**: `level.gd:on_purified`의 `_purified_n ≥ 3` 조건과 보너스(구역 정기·덕망의 50%)를 바꾸지 않는다. 문서화 완료(`purification.md` P1 해소 — 구현 변경 없음, CS-14에서 표기).
- 학살 보상 금지: 처용무·부적 틱으로 쓰러뜨린 요괴도 같은 노래 한 번으로 거두며, 쓰러뜨린 횟수는 어떤 보상도 올리지 않는다.

### 7. 모바일 터치 조작 범위

현재 버튼(`hud.gd`): 베기(430,222 r24)·구르기(384,244 r22)·부적(394,196 r20)·노래(438,172 r22)·처용무(396,150 r22)·교체(360,186 r14)·메뉴. 왼쪽 반화면은 부동 조이스틱, `passby_press = true`.

| 규칙 | 내용 |
|---|---|
| 동시 터치 상한 | 필수 행동은 **조이스틱 + 오른쪽 버튼 1개**(2점 터치)만으로 가능. 버튼 동시 누름(예: 베기 누른 채 구르기)을 요구하는 설계 금지 |
| 신규 버튼 | **없음.** 강 베기는 기존 베기 버튼 길게 누르기 |
| 길게 누르기 | 베기 버튼 하나에만 허용. 진입 0.45초(느린 탭 오인 방지), 충전 게이지는 버튼 둘레 링 + 캐릭터 발치 링(눈이 전투에 있어도 보이게) |
| 타이밍 창 | 받아넘기기 창 **0.15초 이상**(≈9프레임, 터치 지연 50~80ms를 고려해 `batanum`은 0.22초). 구르기 선입력 0.10초 |
| 취소 규칙 | 충전 취소 = 손을 뗌(`c < 0.35`). 별도 취소 제스처 없음 |
| 조준 | 스틱 없으면 현재처럼 70px 자동 조준, 강 베기는 **발동 시점**에 80px 자동 조준 |
| 햅틱 | 만충·받아넘기기·수호부 파괴 시 `Input.vibrate_handheld(20~30ms)` (지원 기기만, 설정에서 끔 가능) |
| 버튼 크기 | 베기 r24 유지(구르기·부적과 이웃 원이 겹치지 않는 한계 — 24+22=46 ≤ 거리 51, 24+20=44 ≈ 거리 44.4). 겹치지 않게 키울 여지가 없다 |
| 피해야 할 것 | 스와이프·더블탭(학의 질주 두 번 누르기는 기존 스킬이라 유지), 화면 겹침 UI, 글로 된 안내 |

## Formulas

### 1장 성장 예산 (설계 입력값)

`Game.need(n) = n × 120` 덕망, 레벨업마다 수련 점수 1. 1장 정화 덕망 추정(normal 18~26 평균 22, elite 80~90 평균 85): 개운포 갯귀 1(22) + 폐가1 6마리(132) + 폐가2 normal 5(110) + 마마귀신(85) = **349** + 한풀이 보너스 50%(폐가1·폐가2 각각 받으면 +66 +98 ≈ 164) = 약 **513** → 누적 필요량 Lv.2 120 / Lv.3 360 / Lv.4 720 이므로 **보스 도착 시 Lv.3 (수련 점수 2점), 한풀이를 다 챙겨도 Lv.3**. 보스 정화 보상 덕망 360 → 보스 후 Lv.4. 따라서:

- 보스 전 스킬 선택은 **1단 스킬 2개**(또는 1개 + 점수 보관). `padong`(3점)은 보스 전에 불가 → 보스 후/2장.
- `attack_mult` Lv.3 = 1.10, Lv.4 = 1.15. 최대 체력 Lv.3 = 112.
- 이 값은 의뢰 보상 덕망을 포함하지 않은 추정이다(코드 미확인). 플레이테스트로 보정(→ Open Questions OQ-3).

### 강 베기 피해

```
c       = 충전 시간 (충전 상태 진입 후 경과, 초)
t       = clamp( (c − 0.35) / (0.90 − 0.35), 0, 1 )          # 0 = 최소, 1 = 만충
mult    = attack_mult × (1.5 if parry_bonus else 1.0) × (결박 보정 1.2 / gyeolbak2 1.4 if 대상.bind_t>0)
dmg     = round( 18 × (1.3 + 1.2·t) × mult )                  # 18은 3타 기본 피해
reach   = 44 + 8·t        (px, 현재 3타 42)
arc     = 1.5 + 0.2·t     (rad, 현재 1.3)
knock   = lerp(280, 320, t) 일반 / lerp(75, 90, t) 보스
적 실피해 = dmg × 상태계수  (장갑 무시: 강 베기는 ARMOR 적용 안 함, stagger 중이면 ×1.5/2.0 유지)
```

| Variable | 값 | 비고 |
|---|---|---|
| CHARGE_ENTER | 0.45초 | 눌림 시점부터. 이전에 떼면 취소 |
| CHARGE_MIN | 0.35초 | 충전 상태 진입 후 |
| CHARGE_FULL | 0.90초 | 〃 |
| CHARGE_MAX | 2.00초 | 자동 발동 |
| 후딜 | 0.35초 | 구르기로 취소 가능 |
| 신명 | +5/체 | 현재 베기 +2.5 |

**예시**: Lv.1 만충 `round(18×2.5×1.0)=45`. Lv.3 만충 `round(18×2.5×1.10)=50`. Lv.3 최소 `round(18×1.3×1.10)=26`. 받아넘기기 후 Lv.3 만충 `round(18×2.5×1.10×1.5)=74`. 마마귀신(HP 70)에게 Lv.3 만충 50 → 3연타 장갑 후 `round(18×1.10×0.6)=12`. 역신(HP 480)에게 Lv.3 만충 50(10.4%) — 열림(×1.5) 중이면 `ceil(50×1.5)=75`(15.6%).
**DPS 비교(Lv.3, 단독·열림 없음)**: 3연타 콤보 `11+11+20=42`/1.0초 ≈ 42 DPS(실제 연결 지연 포함 약 38), 강 베기 만충 50/(0.26+0.45 진입 대기 + 0.90 + 0.35 후딜 = 약 1.96초) ≈ 26 DPS → **강 베기는 단독 DPS 열세**. 이득은 ①장갑 ②예고 끊기 ③열림 창 ④넉백 ⑤신명 +5.

### 받아넘기기 창과 구르기 무적 비율

```
기본 창 = 0.15초,  batanum = 0.22초             # 구르기 t ≤ 창
구르기 사이클 = 0.32(구르기) + 0.25(잠금) = 0.57초
무적 비율(연속) = 0.32 / 0.57 = 56%               # 현재 100%
받아넘기기 가능 비율(구르기 무적 중) = 창/0.32 = 47%(기본) / 69%(batanum)   # 현재 78%
```

### 소리 수지

```
ki' = min(100, ki + 4.0·Δt  − 부적비용  + 8·정화(normal) + 20·정화(elite) + 8·받아넘기기 + 10·수호환급 (+5/피격 심해의 인내))
```

**예시**: 전투 60초, 재생 240 + 정화 6마리×8 = 48 + 받아넘기기 4×8 = 32 = 320 → 화염 25 기준 최대 12.8번, 결박 30이면 10.7번. 재생만이면 60초에 부적 8번(화염)/ 8번(결박) — 현재(6.0/s)는 14번. **실전 기대**: 쉬운 구간은 소리가 남고(정화·재생), 군집·보스에서 부족해진다.

### 신명 수지

```
sin' = clamp(sin + 2.5·(일반 적중 체 수) + 5·(강 베기 적중 체 수) + 15·(받아넘기기) − 12·(피해를 입은 횟수), 0, 100)
```

피해를 입은 횟수는 `hurt()`가 피해 단계(수호부·무적·피격 유예 통과)까지 간 횟수. **예시**: 단독 들개 1마리를 받아넘기기 1회 + 3연타 3체 적중으로 잡으면 15 + 2.5×3 = 22.5. 한 번 맞으면 −12 → 10.5. 처용무까지 약 4~5마리 "깔끔한 교전".

### 정화 회복

```
정화 시 (노래 완료 시점, 범위 90px 안 각 마리): 체력 += max_hp × 0.04 (normal) / × 0.11 (elite),  소리 += 8 (normal) / 20 (elite)
```

Lv.3 (max 112): normal `+4.5 → 4`, elite `+12`. 한 번의 노래로 normal 4마리 정화 = 체력 +16, 소리 +32. 한풀이 성립 시 체력 +15% max_hp(추가, 구역 1회).

### 난이도 곡선 (1장 사망 목표)

기준: 1장 전체 40~60분(`game-concept.md`). **사망** = `Player._die` 호출 1회. 목표(첫 플레이어, 숙련 아님, 터치 기기):

| 구간 | 평균 사망 | 근거 | 위험 시 조치 |
|---|---|---|---|
| 개운포 튜토리얼 (갯귀) | **0** | `gentle_hits = 3`로 피해 0 | — |
| 폐가 1층 (6마리) | **0.6** | 들개·역귀 4마리가 대부분, 물귀신·처녀귀신 기믹이 처음 등장 | 소리 재생 4.0 → 5.0 |
| 폐가 2층 (정예 포함 6마리 + 독기 함정) | **0.8** | 마마귀신 첫 만남, 달걀귀신 은신 | 마마귀신 장갑 0.6 → 0.7 |
| 역신 | **1.8** (중앙 2, p90 5) | 패턴 4종 학습 | 보스 HP 480 → 420, 열림 1.2 → 1.4초 |
| **1장 합계** | **중앙 3, 허용 2~5, p90 ≤ 7** | | 어느 구간이든 p90을 넘기면 위 조치 |

보스 전투 시간: 숙련 90~150초, 첫 도전 3~4분(재도전 포함). 보스 막판 체감: "사망 1~2회 후 패턴 순서를 외우고 3~4번째에 처음 이긴다"가 설계 의도. **측정**: CS-07(사망 카운터, 구역별)과 플레이테스트 리포트(`agent-rules.md` #5)의 구역별 소감을 함께 본다. 한 구간 평균이 목표 ×2를 넘으면 조치 1개를 적용.

### 역신 전투 시간 모델 (기대값, 불확실)

```
1사이클(안개·기침·졸개·기침) ≈ (대기 1.4 + 시전 0.9) + (1.0 + 열림 1.2) + (0.8 + 졸개 처리 ~8) + (1.0 + 열림 1.2) ≈ 16초
열림 2회×1.2초 + 시전 노출 2회×~0.9초 → 사이클당 가한 피해 ≈ 열림 3연타/강 베기 2번(42~75) + 대기 중 견제 ≈ 90~150
HP 480 → 3~5사이클 → 50~80초(순수 공격 시간), 이동·회피·졸개 포함 90~150초
```

수치는 계산 추정이다(실측 아님) — 플레이테스트에서 열림 길이·보스 HP를 조정한다.

## Edge Cases

| Scenario | Expected Behavior | Rationale |
|---|---|---|
| 상호작용 가능한 NPC 앞에서 베기를 길게 누름 | 말 걸기가 처리되면 공격·차징 모두 일어나지 않는다 | `interact.call()` 우선(현재 규칙 5) |
| 1타가 헛스윙이고 버튼을 계속 누름 | 0.45초 시점에 충전 진입(적이 없어도) | 입력 일관성. 적이 없으면 충전은 취소해도 무손실 |
| 충전 도중 대사/컷신으로 `locked` | 충전 취소(발동 없음) | 컷신 중 전투 입력 무시 |
| 충전 중 수호부로 막은 피격 | 충전 유지, 환급 +10 | S2 |
| 충전 중 `c ≥ 0.35`에서 구르기 입력 | 무시 | D2 위험. 충전 해제만 가능(손 떼기 = 발동) |
| 충전 중 `c < 0.35`에서 구르기 | 충전 취소 + 구르기 즉시 | 늦기 전 회피 가능 |
| 충전 중 처용무 가능(신명 100) | `dance` 입력은 `state in [move, attack]`만 받으므로 `charge`도 포함시킨다 | 신명 100에서 막힌 충전은 답답함 |
| 충전 발동 대상이 0 | 후딜 0.35초만 | 헛스윙 비용 = 시간 |
| 받아넘기기 직후 0.3초 쿨다운 중 접촉 | 무적은 유지, 보상 없음(현재 규칙) | 쿨다운 유지 |
| 구르기 잠금 중 구르기 입력 | 선입력 저장(잠금 끝 0.10초 전부터 유효), 이전 입력은 버림 | 터치 지연 완충 |
| 학의 질주 두 번째 입력 | 잠금 무시 | `hak` 보상 |
| 안개 틱(`kind="miasma"`)이 수호부와 | 0 피해·충전 유지·타격 시 신명 −12도 없음 | 독기 대응 정답 |
| 안개 틱이 구르기 무적 중 | 받아넘기기 발동 안 함(`melee=false`) | 구버전의 의도치 않은 받아넘기기 제거 |
| 투사체·충격파 | 구르기 중이면 아예 맞지 않음(현재), 받아넘기기 대상 아님 | 구르기 정답 보존 |
| 수호부 `_guard_t` 0.4초 동안 다른 적의 `stun` | 같이 막힘 | 한 번의 막기가 같은 프레임 근처 효과를 덮음 |
| 마마귀신이 시전 후 후딜 중 강 베기 | stagger 배율 1.5(장갑 해제) 적용, 장갑 무시와 중복 곱하지 않음 | `STAGGER_MULT`가 우선 |
| 해태에게 화염부 | 현재와 같이 흡수(불 금지는 서사/도감에서 안내) | 2장 범위 |
| 정화 직전 쓰러진 요괴에 강 베기 | 맞지 않음(`downed` 그룹) | 현재 규칙 |

## Acceptance Criteria

(검증 훅은 `CLAUDE.md` "검증": `--sin=100`, `--skills=id,id`, `--sp=N`, `--test-enemies=키`, `--level=<id>`. 신규 훅은 CS-13에서 정의.)

**받아넘기기·구르기**
- [ ] 스킬 없이(`--skills=` 빈 값) `--test-enemies=dog`: 구르기 시작 후 0.15초 안에 들개 접촉 → "받아넘기기" 표시·신명 +15·소리 +8·다음 타 ×2. 0.15초 이후(0.15~0.32초) 접촉 → 피해만 무시, 보상 없음.
- [ ] `--skills=batanum`: 창이 0.22초, 성공 시 정면 80px 요괴가 밀쳐진다.
- [ ] 안개 틱·투사체·충격파가 구르기 무적 중에 닿아도 "받아넘기기"가 뜨지 않는다.
- [ ] 구르기를 연속으로 누르면 두 번째 구르기는 첫 번째 종료 0.25초 뒤에 시작된다(선입력 반영). `hak` 학의 질주는 이 잠금을 무시한다.
- [ ] 역신의 기침 숨결·펄스 접촉에서 받아넘기기가 발동한다.

**강 베기**
- [ ] 베기 탭은 현재와 같이 즉시 1타가 나가고 3연타 이어치기가 유지된다(회귀 없음).
- [ ] 베기를 0.45초 이상 누르고 있으면 충전 상태(이동 불가, 게이지 표시). 0.45초 전에 떼면 아무 일도 없다.
- [ ] 충전 `c < 0.35`에 떼면 취소(후딜 없음), `c ≥ 0.35`면 발동, `c ≥ 0.90`이면 만충(Lv.1 피해 45, 사거리 52, 넉백 320).
- [ ] 충전 중 피해를 입으면 취소된다. 수호부로 막은 피격은 취소시키지 않는다.
- [ ] `c ≥ 0.35`에서 구르기 입력이 무시되고 `c < 0.35`에서는 구르기로 취소된다.
- [ ] 강 베기 한 번으로 마마귀신(HP 70)이 장갑 무시로 정상 피해를 받는다(3연타는 ×0.6).
- [ ] 소리가 줄지 않는다(소리 0 소모).
- [ ] 쓰러진 요괴는 차징 일격에도 `downed`로 남아 노래로 정화된다(죽지 않음).
- [ ] 상호작용 가능 대상 앞에서 길게 눌러도 차징이 시작되지 않는다.

**수호부·독기**
- [ ] 수호부가 켜진 상태에서 물귀신/처녀귀신/손각시의 공격을 맞으면 피해 0, 기절·끌림·둔화 모두 없음.
- [ ] 수호부가 켜진 동안 안개 틱·독기 함정 틱은 0 피해이고 수호부는 소모되지 않는다(10초 지속).
- [ ] 수호부가 직접 타격을 막아 사라질 때 소리 +10.
- [ ] 구르기 무적 중 `slow()`가 무시된다.

**적 정답표**
- [ ] 헛돌진한 들개가 0.5초 후딜 상태가 되고 이때 받는 피해 ×1.5. 갯귀 후딜 0.8초, 마마귀신 시전 후 1.2초.
- [ ] 마마귀신에게 3연타 피해 ×0.6, 후딜 중에는 ×1.5(장갑 해제).
- [ ] 결박부는 110px 안에서 가장 많은 적을 반경 40 안에 담는 위치에 깔린다(졸개 3마리 동시 포획 가능).
- [ ] 결박된 적이 화염 틱을 맞으면 8, 맞지 않은 적은 5.

**자원**
- [ ] 소리 재생 초당 4.0, 정화 시 소리 +8(normal)/+20(elite)·체력 +4%/+11%, 피해를 입으면 신명 −12(0 하한).
- [ ] 한 번의 노래로 4마리 정화 시 체력 약 +16(Lv.3), 소리 +32.

**역신**
- [ ] 기침 숨결 후 1.2초(2페이즈 0.9초) 동안 역신이 움직이지 않고 받는 피해가 ×1.5. 풀 충전 강 베기를 열림 중 맞히면 `ceil(50×1.5)=75`(Lv.3).
- [ ] 졸개 소환 시전 0.8초 중 풀 충전 강 베기가 맞으면 소환이 취소되고 역신이 1.2초 stagger.
- [ ] 2페이즈 전환 시 1.2초 열림, 소리 +30, 안개 제거.
- [ ] 패턴 순서가 1페이즈 `안개-기침-졸개-기침`, 2페이즈 `안개-기침-졸개-기침-안개-졸개` 그대로이다.
- [ ] 무릎 꿇은 역신은 처용가로만 끝나고, 쓰러진 졸개가 일괄 정화되며, 한풀이 규칙(최소 3)은 변하지 않는다.

**난이도·측정**
- [ ] 구역별 사망 카운터가 세이브에 기록되고 플레이테스트 리포트에서 읽을 수 있다. 목표(중앙 3, p90 ≤ 7)를 벗어나면 Tuning Knobs의 지정 조치를 적용한다.

**터치**
- [ ] 393×852 기기(가로)에서 조이스틱 + 베기 버튼 한 손가락으로 강 베기를 충전·발동할 수 있다(별도 버튼 없음). 버튼 반경은 이웃 원과 겹치지 않는다.
- [ ] 만충·받아넘기기에서 햅틱이 나온다(지원 기기).

### P0

**CS-01 · 받아넘기기 기본 개방·재설계·구르기 잠금** — `player.gd`, `enemy.gd`, `boss.gd`, `skills.gd`
- `player.gd`: `hurt(dmg, dir, melee := false, kind := "")`로 시그니처 확장. 받아넘기기 조건에서 `Game.has_skill("batanum")` 제거, `melee` 요구 추가, `t <= _parry_window()` (`_parry_window()` = `PARRY_WINDOW`, `batanum`이면 `PARRY_WINDOW_SKILL`).

**CS-02 · 강 베기 (차징)** — `player.gd`, `enemy.gd`, `boss.gd`
- `player.gd`: 상수 `CHARGE_ENTER/MIN/FULL/MAX`; 변수 `_hold_t`, `_charge_c`, 상태 `"charge"`(+ `_charge_pending`). `_physics_process`: `attack` 눌림 시작 시 `_hold_t = 0`, 누르는 동안 증가, `Input.is_action_pressed("attack")`; 1타 종료(`_attack`의 `k >= 1.0` 분기)에서 버튼이 눌려 있고 `queued`가 없으면 `_charge_pending = true`로 `move`에 복귀(콤보 이어치기는 `queued`일 때만 기존대로). `_hold_t >= CHARGE_ENTER`이고 상호작용 가능 대상이 없으면(`interact` 재호출 금지 — `hud.set_talk` 상태 변수 사용) `state = "charge"`.

- 새 함수 `_release_charge()` → `_resolve_charged(c_dict, base)`: 위력은 Formulas 공식, `take_hit(dmg, dir, true, false, true)`(5번째 인자 `charged`), 신명 `SIN_PER_CHARGED = 5.0`, 후딜 0.35초(`state = "attack"` 재사용, `hit_done = true`).

- `boss.gd:take_hit`: 동일 시그니처, 넉백 `lerp(75, 90)`, `charged`가 시전 상태(fog/cough/clones)에 맞으면 중단(CS-06).

## 결정 근거 요약 (기획팀 메모)

- 받아넘기기를 기본 개방하면서 창을 줄이고 구르기에 잠금을 둔 이유: 개방만 하면 구르기 연타 = 공짜 신명이 되어 "적마다 정답이 다르다"가 무너진다.
- `batanum`의 id를 유지하고 효과만 바꾼 이유: 세이브 호환, 춤 1단 슬롯 유지, 수련 점수 환불 불필요.
- 강 베기가 DPS상 열세인 이유: 우위 선택지가 되면 3연타가 사라진다. 장갑·예고 끊기·긴 후딜 창이 있는 곳에서만 이득이어야 "언제 쓸지"가 생긴다.
- 보스 순서를 고정한 이유: 읽어서 외우는 즐거움과 사망 횟수 통제를 동시에 얻는다. 무작위 순서는 난이도 변동성이 크다.
