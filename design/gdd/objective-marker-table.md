## 3. 신규 목표표 (문구 + 마커 대상)

### 3.1 읽는 법

- **상태 ID**: 코드 `Story.objective_info()` 의 `id`. 형식 `ch1.<레벨>.<이름>`.
- **조건**: `Game.level_id` + 플래그. **위에서 아래로 처음 맞는 행**이 현재 목표(기존 `objective()` 와 같은 우선순위 방식).
- **문구**: UI 간결체(해라체 아님, 명사형·평서 `~한다`), **공백 포함 18자 이하**. 시대극 말투(~하오/~소)는 대사에만 쓴다.
- **대상**: footprint 좌표. 종류 — `npc`(NPC 노드 위치 추적) · `interact`(상호작용 지점) · `exit`(출구/게이트 사각형 중심) · `node`(움직이는 요괴) · `area`(트리거 사각형 중심).
- **경유**: 직선이 막힐 때 마커가 먼저 향할 지점(`via`). `미검증`은 `walkability` 로 실제 경로를 확인해야 함(§6 T2).
- **금칙어**: 이 행의 문구에 **쓰면 안 되는 말**. 자체 검토는 이 열로 기계적으로 한다(설계서 §3.3 전체 목록).
