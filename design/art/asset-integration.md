# 외부 도트 에셋 세트 검토 — 통합안

> 작성: art-director, 2026-10-12. 문서만. 스프라이트·코드·`art/*.py`는 건드리지 않았다.
> 대상: `~/workspace/goals/rpg/files/game-assets/` (사용자 진술: 구글드라이브 '신처용가-게임에셋'과 동일 — **드라이브와의 일치는 확인하지 않음**). 사용자 말: "그대로 써도 되고 업그레이드해도 자유".
> 방법: 모든 PNG/WEBP를 직접 열어 보고(확대 대조 포함), 픽셀 통계는 Pillow/NumPy로 쟀다. 현행 쪽은 `src/assets/sprites/*.png`, `art/*.py`, `src/scripts/enemy.gd`·`boss.gd`·`bestiary.gd`와 대조했다.

## 0. 결론 먼저

1. **세트는 "게임용 스프라이트 시트"가 아니라 "AI 생성 일러스트를 도트풍으로 잘라 둔 것"이다.** 파일 수 279 = 이미지 205(WEBP 70 + game-ready PNG 135) + JSON 74. 원본은 검은 배경 RGB(알파 없음), `game-ready/`는 이를 배경 제거·높이 64/96으로 축소한 것이다.
2. **현행 파이프라인과 가장 크게 어긋나는 점 4가지.**
   - 프레임: 요괴당 **idle 1장 + 공격 3장**뿐. `Enemy`는 7프레임(move0-3·tell·strike·hurt)을 요구한다(`enemy.gd` KINDS `anims`).
   - **idle과 공격 프레임이 서로 다른 생성물**이라 같은 캐릭터가 아니다(색·종·구도 다름). 예: 불개 idle=숯빛 개+해·달, 공격=붉은 시바견; 여우 졸개 idle=보라, 공격=주황; 장승 idle=돌 거인, 공격=기둥 장승; 손각시 idle=흰머리, 공격=갈색머리; 이무기 idle=어두운 뱀, 공격=알록달록한 용 흉상.
   - 픽셀 규율: game-ready는 한 장에 **약 870~7,500색(idle만이면 약 890~4,800), 반투명 픽셀 약 700~6,800개**(실측). 현행 손그림 요괴는 **15~21색, 반투명 0**, 처용·역신 같은 3D 인형계도 반투명 0·170~460색.
   - 복식: 갓·전립(저승사자 공격·망자 군단 공격 프레임·산신령), 삿갓(농부), 곤룡포풍 왕 — 신라 복식 규칙 위반이 세트 안에 이미 있다.
3. **판정 요약**: 지형 9장·효과 1장·아이템·왕/산신령 등은 "그대로" 게임에 못 넣지만, **레퍼런스·도감 일러스트·보스 베이스 아트로는 가치가 크다.** 인게임 요괴를 이 세트로 *교체*하는 것은 권하지 않는다(현행 20종이 6~7프레임으로 이미 동작). **미구현 보스·정예(2~5장)의 시작 그림**으로 쓰는 게 가장 효율적이다 (§c).

## (0) 출처·생성 도구 메타데이터

- 각 `*.json`(73개)은 `{"text": "{\"status\":\"ok\",\"snapshot_id\":\"…\"}", "attachments":[{"url": "https://scontent.xx.fbcdn.net/…webp", "media_handle": "…"}]}` 형태다. 파일명은 `media-generation-<이름>-<해시>.webp`, JSON은 `…-<epoch>.json`(epoch 1791628377 = 2026-10-10 10:32 UTC ~ 1791630045 = 11:00 UTC; 약 28분간 생성).
- 따라서 생성 도구는 "media-generation" 호출이며 결과가 **Meta의 CDN(fbcdn.net)** 에 올라간 이미지다. 모델명·프롬프트·라이선스 문구는 **메타데이터에 없다.** (Meta AI 이미지 생성으로 *추정*되나 기록에서 확인되지는 않음.)
- 실패 기록 2건: `enemy-plaguedog`(역병 들개)와 `ch3-bride-atk` 1회는 `integrity_check_failed / media_guard`로 생성 거부 — 그래서 **역병 들개 그림이 세트에 없다.** (별도: `last-upload-handles.json`은 실패가 아니라 참조 이미지 ID 하나.)
- `ASSET_MANIFEST.json`: monsters 25 / npc 6 / items 4 / terrain 9 항목. effects는 매니페스트에 없다(파일은 있음, `effects/…effects-set…webp`).
- **라이선스 기록(제안)**: "사용자 본인 생성물로 간주(사용자 지시). 생성 도구·약관은 미확인." 상업 배포 전 사용자가 도구의 약관(출력물 사용권)을 확인하고 한 줄로 남길 것을 권한다. `technical-preferences.md:55`("외부 에셋 사용 금지(CC0/MIT 확인 전)")와 `CLAUDE.md`("외부 에셋 없음")는 이 세트를 쓰는 순간 개정이 필요하다 — **사용자 승인 사항**(§d-7).

## (d) 통합 방법

1. **위치/이름**: `art/import_external.py`(신설)와 데이터 `art/external/`(원본 WEBP·JSON 보관, 메타데이터 `SOURCES.md`에 §0 출처 기록). `art/build.py`와 같은 "한 줄로 재생성" 원칙을 따른다. 산출은 `src/assets/sprites/`에 `x_<게임키>.png` 같은 **시험용 접두**로 쓰고(예: `x_mama.png`), 검증이 끝나면 `KINDS`의 `sheet` 값만 바꾼다(현행 파일을 덮어쓰지 않는다).
2. **원본에서 다시 만든다**: game-ready PNG를 늘리거나 줄이지 말고 원본 WEBP에서 시작한다(game-ready는 비정수 축소로 이미 혼합색이 있음).
   - 배경 키: 검은 배경은 가장자리에서 flood-fill로만 제거(내부의 어두운 부분 보존). 마마·불개의 번지는 불꽃/독무는 별도 가산 레이어로 분리하거나 알파 임계처리(≥128 → 1, 그 외 0).
3. **정수 배율**: 오프라인에서 **최종 해상도(1×)** 로 만든다. 게임에서 스프라이트를 확대하지 않는다(480×270 정수 배율 뷰포트가 이미 확대 담당). 목표 키는 현행 셀과 같은 범위: 일반 몹 42~58px(`KINDS`의 `cell.y`), 정예 44~72px, 보스 96~136px(`boss.gd` 셀 164). 사람형은 36px 근방. 같은 폭/높이로 줄이는 알고리즘은 영역 평균(box) → 팔레트 양자화 순서.
4. **팔레트 정규화**: ① 종당 전역 램프 16~24색을 OKLab K-means로 뽑고 ② 디더 없이 최근접 매핑 ③ 그림자는 청보라 쪽·빛은 황색 쪽으로 이동(`people.py:ramp` 규칙) ④ 채도 상한을 현행 요괴 분포(평균 s≤0.67) 이하로 클램프, 공격 프레임 명도(v>0.7)는 낮춤 ⑤ 알파는 0/255만 ⑥ 1px 먹색 `#07060b` 셀아웃 외곽선(`props.py:INK`) 추가.
5. **프레임 구성**(7프레임, `enemy.gd` 규약): `move0-3` = idle을 1px 상하·좌우 오프셋으로 2~4프레임 합성(떠다니는 몬스터는 float, 보행형은 다리 영역만 분리 필요), `tell` = `atk_1`, `strike` = `atk_2`(또는 `atk_3`), `hurt` = idle + 백색 플래시 + 넉백 오프셋. **단 idle과 atk가 다른 캐릭터인 종은 tell/strike를 쓰지 말고 idle에서 파생**한다. 셀은 모든 프레임이 같은 크기, 발끝(또는 부유 요괴의 몸통 기준선)을 `feet` 행에 맞춰 하단 중앙 정렬(현재 game-ready는 프레임마다 폭이 달라 정렬 정보가 없음).
6. **노멀맵**: 정규화 후 `art/normals.py`로 `<name>_n.png` 생성(알파/외곽선 기준 부풀림 모델이라 별도 입력 불필요). `Tex.lit`가 자동 로드.
7. **정책 개정(사용자 승인 필요)**: `technical-preferences.md:55`와 `CLAUDE.md` 아트 파이프라인 제목을 "외부 에셋은 사용자 본인 생성물에 한해, `art/external/SOURCES.md`에 출처·도구를 기록하고 `import_external.py`를 거친 것만 허용"으로 바꿔야 한다. 이 PR은 문서만 두며 해당 파일은 바꾸지 않았다.
8. **검증 절차**: `--test-enemies=<키>` 캡처로 현행과 나란히 비교(색 수·실루엣·tell 가독), 스크린샷으로 신라 복식 규칙 확인, 노멀맵 라이트 점검.
9. **네이밍**: 원본 `ch1-mama` → 게임 키 `mama`(§a 표). 보스는 키 신설이 필요하므로(`boss_plagueking` 등) 신규 장면 ID와 함께 별도 제안.
