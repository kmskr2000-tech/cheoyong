# 에셋 겹침 점검 리포트 (1장 6맵) — 프로그래밍팀-에셋겹침수정

사장님 폰 피드백 7번 "상점 등 에셋 겹침 — 재배치 필요" 대응. 브랜치 `prog/overlap-fix` (origin/main 30e9796 기준).
땅그림·에셋 파일은 건드리지 않았고 `levels.gd` 좌표(+ 길잡이 좌표 1곳)만 조정했다.

## 도구
- `tests/overlap_check.sh [맵...]` → `tests/godot/overlap_check.gd` (헤드리스, 맵당 수 초). 1장 6맵이 기본, 0건이면 통과.
  - levels.gd 의 props·npcs·interact·exits·gates·triggers·spawns 를 `level.lift()` 와 같은 규칙(lift·lift_size, 스프라이트 오프셋, NPC 3/4 정면 프레임)으로 화면 좌표에 올리고, **불투명 픽셀(알파)이 6px 이상 겹치는지** 센다.
  - 분류: `OVERLAP`(소품·NPC 스프라이트끼리) / `LABEL`(상호작용 지점이 다른 스프라이트 위) / `AMBIGUOUS`(말 걸기 대상 둘이 20px 안 → 한 자리에서 둘 다 TALK_RANGE 26 안) / `BLOCKED`(출구·문·트리거·스폰이 소품·NPC 충돌에 걸림).
  - 의도된 접촉은 스크립트 `ALLOW` 표에 사유와 함께 적어 면제(현재 비어 있음).
- `tests/overlap_shots.py <출력폴더> <접두어> <맵>:<x>:<y>[:<flags>] ...` — footprint 좌표를 화면 좌표로 올려 처용을 옆에 세우고 캡처, 대상 주변 160x90 을 4배(640x360)로 저장. 전/후를 같은 좌표·같은 플래그로 찍는다. (`CROP=w,h` 로 크기 변경, `NOLOCK=1` 은 godot.lock 생략)
- 땅그림에 이미 그려진 건물과의 중복은 자동 검출이 안 되어 **육안**으로 소품마다 캡처해 확인했다(아래 '육안 확인').
