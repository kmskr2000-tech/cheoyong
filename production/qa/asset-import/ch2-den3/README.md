# 굴3(den3) 두억시니의 방 — 전용 지형 (아트팀-굴3지형, 브랜치 asset/ch2-den3-terrain)

M2 의 코드 판석 바닥을 일러스트 소재 리페인트로 교체. 걷기 기하(`ch2m2_maps.MAPS['den3']`)·충돌 `den3.json`(origin/main 과 diff 0)·gate/spawn/exit/anchors/mortar_altar/횃불/기타 소품은 그대로다.
- 생성: `python3 art/ch2den3_terrain.py` (den3 만 다시 만든다). 바닥 = dungeon 원본의 진짜 바닥 퀼팅(뒤집기 포함)+보라회색 톤, 의식대(타원 r40/r98/r130, 섹터 석판, 보라 상감선, 소환점 8 = 45도·r130, 설계서 §4.6), 제단에서 방사하는 균열, 검은 물웅덩이, 북·남 벽 = den1 파도문 프리즈 띠, 서·동 벽 = 같은 갓돌 줄을 세운 것.
- levels.gd 변경(den3 소품 좌표만): 기둥 y 129→126 / 269→274 (기둥 두 쌍 24px 겹침 해소), `old_tools_broom` (75,227)→(84,247) (gate 트리거와 충돌 겹침 해소). 엄폐 의도(4기둥 사각 배치)는 유지.
- 캡처: `before/` `after/`(게임 안), `compare_den3_*_4x.png`(원본 PNG 4배 전/후), `overlay_den3.png`(걷기 마스크 경계 빨강 = 그림의 벽 안쪽 가장자리와 일치).
- 한계: 바닥 판석 격자가 균일하게 촘촘함(원본 큰 판석보다 작게 읽힘), 검은 웅덩이 4곳 중 3곳은 코드 도형(항아리 있는 1곳만 원본 스탬프), ambient 0.34 + 점광원 때문에 게임 안에서는 여전히 푸른 보라로 보인다(톤은 보라회색으로 옮겼으나 ambient 는 불변).
