# 2장 M2 부족 에셋 목록 (프로그래밍팀 → 아트팀)

M2(old_village · den1 · den2 · den3)는 **전용 지형·소품이 없어 1장 땅그림으로 폴백**해 동작한다. 정본: `design/levels/ch2-dokkaebigol.md` §4.3~4.6, §11. 폴백의 한계를 숨기지 않고 적는다 — 아래 '한계' 열이 실제 플레이에서 어색하게 보이는 지점이다.
전용 지형이 들어오면 `levels.gd` 의 `ground`·소품·좌표를 교체하고 `tests/art_walk.sh`·`tests/ch2_aggro.sh` 의 좌표(`walkability.gd` ROUTES·LIVE 표)를 새 그림에 맞춰 갱신한다.

## 지형 (땅그림 + 충돌 json)
