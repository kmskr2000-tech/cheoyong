# 걷기 애니메이션 + 이동속도 (폰 피드백 3·8번) — 프로그래밍팀

## 1. 원인 조사 (피드백 3번 "이동 모션 없음")
구분 결과: **프레임은 있고 쓰고 있다. 다만 (a) 위/아래 사이클의 시각 변화가 거의 없고 (b) 재생이 속도·충돌과 무관해 걷는 느낌이 안 난다.**
- `cheoyong.png`(64x64 x105): 걷기 프레임 있음 — down 3-6, up 7-10, right 11-14, left 는 right 를 flip. 방향 누락 없음(4방향, 대각선은 지배 축으로 4방향에 매핑 — art 가 가진 방향 수 그대로).
- 프레임 해시 비교: 사이클 4프레임 중 down 4==6, up 8==10, right 12==14 → 실제 포즈는 3개(접촉-통과-접촉-통과). down/up 은 다리 변화가 몇 픽셀뿐이라 이동 중에도 거의 정지 화면처럼 보임(sheet 확인). right 는 보폭이 크게 보임.
- `player.gd _move`(수정 전): `row + "_walk"` 를 8fps 로 고정 재생. 이동 속도가 달라져도(느려짐 0.5x·연풍 1.25x) 같은 속도로 돎 → 미끄러짐. 벽/장애물에 막혀 제자리여도 입력만 있으면 walk 재생(캡처: gyeongju (259,250) 에서 위치 고정인데 `right_walk` 프레임이 계속 돎).
- 몸 전체 상하 움직임 없음 → 프레임 변화가 작은 down/up 에서 모션이 안 보임.
- 공격·구르기·피격·대사 상태는 `_pose`/`_roll`/hurt 분기라 walk 와 충돌하지 않음(`_move` 에서만 walk 선택). `_run` 애니(78-86)는 정의만 있고 미사용(구르기는 `_roll` 컷 사용).
- NPC·요괴: 범위 밖, 문서만. `npc.gd walk_to(p, speed=40)` 은 컷신 이동용으로 걷기 프레임 선택 여부 미확인(후속 검토 대상). 요괴는 `enemy.gd` 8fps 고정 재생(속도 연동 없음) — 같은 유형.

## 2. 수정 (art 프레임·인덱스 불변)
- 보폭 동기: `sprite.speed_scale = 실제속도 / WALK_REF(72)` — 한 걸음 길이를 기존 값으로 고정(속도 +28% → 사이클 +28% 빠름, 느려짐/연풍/신명에도 자동 반영).
- 홀수 프레임(통과 자세)마다 몸을 1px 들어올리는 bob(정수 픽셀, 픽셀퍼펙트 유지) → down/up 에서도 걸음이 보임.
- 실제로 움직일 때만 walk(`get_real_velocity > 6`), 막히면 idle. 정지 시 idle 복귀는 기존 분기.
- 다른 상태 누수 방지: `_physics_process` 맨 앞에서 speed_scale=1, offset 초기화(공격·구르기·피격·대사에서 bob 잔류 없음).
- art/hero.py 신규 프레임: 추가하지 않음(bob+동기만으로 처리; 추가 필요하면 후속).

## 3. 이동속도 (피드백 8번 "너무 느림")
| 항목 | 전 | 후 |
|---|---|---|
| SPEED | 72 | 92 (+27.8%) |
| ROLL_SPEED | 200 | 256 (+28%, 구르기 시간·무적 불변) |
| 걷기 프레임레이트 | 8fps 고정 | 8fps x 속도/72 (92 에서 약 10.2fps) |
| combat_tuning.gd | - | 변경 없음(받아넘기기 창 등 불변) |

근거: +28% = 폰 가로 480x270 에서 맵 횡단을 체감 1/4 단축하는 중간값(+25~30% 요청 범위). 구르기 꼬리 속도는 `ROLL_SPEED*0.4` 라 200 그대로면 80 < 새 걷기 92 → 구르기 끝이 걷기보다 느려짐. 같은 비율로 올려 꼬리 102 > 92.

맵 횡단(맵 폭 px / 속도, 직선 이동 이론값. 지형 폭 = 땅그림 가로):
| 맵 | 폭 | 72px/s | 92px/s |
|---|---|---|---|
| jiri_path(최대) | 1120 | 15.6s | 12.2s |
| hwagae | 800 | 11.1s | 8.7s |
| pyega2 | 768 | 10.7s | 8.3s |
| 경주(village) | 640 | 8.9s | 7.0s |
| palace | 512 | 7.1s | 5.6s |

균형 점검(코드 근거):
- 구르기: 거리 약 45px → 약 58px(+28%), 평균 속도/걷기 비율 2.8→2.2 로 낮아졌지만 여전히 구르기가 빠름. 시간(0.32s)·ROLL_LOCK·무적 불변이라 타이밍 테스트 무영향.
- 적 추격 속도(enemy.gd cfg speed): dog 62, pado 60, jangsanbeom 58, sangun 56, bulgae 56(강화 84), fox 40 외 대부분 ≤50. 이전엔 플레이어 72 로 dog 도 추월 가능했고, 지금 92 는 전 요괴보다 빠름(bulgae 강화 84 제외 시 격차 +50% 이상). **도주 용이성이 올라가는 것은 의도된 부작용** — 추격 요괴 속도 상향이 필요하면 기획팀 판단(범위 밖, 변경 안 함).
- 넉백(160 px/s)·공격 돌진·어그로 거리는 불변. 어그로 도달 시간은 ch2_aggro 로 확인(아래).
