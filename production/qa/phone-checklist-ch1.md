# 1장 폰 플레이 체크리스트

폰에서 1장을 처음부터 끝까지 한 번 해 보면서 적는 종이입니다. 잘하려고 하지 않아도 됩니다.
막히면 멈추지 말고 "막히면 적을 것" 칸에 **어디서, 무엇을 눌렀는데, 어떻게 됐는지**만 적어 주세요.
화면을 찍어 두면 더 좋습니다. (전체 약 40~60분 / 15분마다 칸이 하나씩)

## 시작 전 (2분)
- [ ] 폰 이름과 브라우저: ______________ (예: 아이폰 14, 사파리)
- [ ] 화면을 가로로 돌렸다 / 무음 스위치(옆 버튼)를 껐다 / 소리를 중간 이상으로 올렸다
- [ ] 주소를 열었다. 처음 뜬 화면: ______________
- [ ] 게임 시작 시각: ____시 ____분

## 구간 0. 타이틀 (처음 1분)
**여기서 확인할 것**
- [ ] 제목 화면이 나온다. 글씨가 잘리지 않는다.
- [ ] **소리**: 화면을 한 번 눌러야 음악이 나왔다 / 누르기 전부터 나왔다 / 끝까지 안 나왔다 (하나에 동그라미)
- [ ] 메뉴 글씨(처음부터, 이어하기)를 손가락으로 눌렀을 때 한 번에 눌린다.
- [ ] 아래쪽에 "본 게임은 삼국유사 … 픽션입니다" 문구가 보인다.

**막히면 적을 것**: ______________________________

## 구간 1. 인트로 + 백사장 (0~15분)
**여기서 확인할 것**
- [ ] 인트로 그림이 넘어간다. 오른쪽 위 "건너뛰기"가 눌린다.
- [ ] 모래 위에서 눈을 뜬 뒤 움직일 수 있다.
- [ ] **조이스틱**: 왼쪽 화면에 엄지를 대면 조이스틱이 생긴다. 손을 떼면 멈춘다.
- [ ] 반짝이는 대나무 피리를 주웠다. 그 뒤 오른쪽에 "노래" 버튼이 생겼다.
- [ ] 갯귀(바다 요괴) 싸움: 빛나는 버튼 하나만 따라 눌러서 베기, 구르기, 노래(정화)까지 했다. 글 설명 없이 이해됐다.
- [ ] 수령이 나오고 "서라벌" 글자가 뜨며 장면이 바뀌었다.
- [ ] 걷다가 **문/가장자리를 넘어 장면이 바뀐 직후**, 손가락을 뗐는데 캐릭터가 혼자 계속 걷지 않았다. (혼자 걸으면 꼭 적어 주세요)

**HUD 겹침**
- [ ] 오른쪽 아래 버튼들(공격·구르기·부적·노래)이 서로 겹쳐 보이지 않는다.
- [ ] 공격을 누르려다 구르기나 부적이 같이 나간 적: 없다 / 있다 (____번)
- [ ] 왼쪽 위 체력·기력 막대, 오른쪽 위 메뉴 버튼이 둥근 모서리/노치에 가려지지 않는다.

**막히면 적을 것**: ______________________________

## 구간 2. 경주 마을 (15~30분)
**여기서 확인할 것**
- [ ] 난영과 대화가 된다. 글자를 화면 아무 데나 눌러서 넘길 수 있다.
- [ ] 금줄 집 아이를 노래로 정화했다.
- [ ] 약방에서 물건을 샀다. **한 번 눌렀는데 두 개 사지지 않았다.** (샀다 개수: ____)
- [ ] 선택지(쉬어간다/그만둔다, 상점 목록) 글씨를 눌렀을 때 옆 줄이 눌리지 않았다.
- [ ] 집에서 쉬었다. "기록됨" 글이 떴다. → **세이브 1회 완료**
- [ ] 봄·여름·가을 세 장의 글 장면이 나오고, 밤이 왔다.
- [ ] 마을 사람 옷(관모, 금관, 옷 색)이 **신라 느낌**이다 / 조선 사극 느낌(갓·사모 같은 것)이 난다 (보이는 사람: ______)

**막히면 적을 것**: ______________________________

## 구간 3. 관아와 폐가 (30~45분)
**여기서 확인할 것**
- [ ] 관아 형방과 대화하고 인삼정기탕 2개를 받았다.
- [ ] 폐가 마당의 요괴들(개, 귀신 등)을 싸우거나 피해서 위층으로 올라갔다.
- [ ] 위층 바닥의 독기(연기)가 보이고, 맞기 전에 피할 수 있었다.
- [ ] 약(행낭)을 꺼내 썼다. 오른쪽 위 메뉴 버튼이 한 번에 눌린다.
- [ ] **체감 프레임** (하나에 동그라미)
  - 매끄럽다 / 가끔 끊긴다(싸울 때만) / 자주 끊겨서 불편하다
  - 가장 끊긴 곳: ______________
- [ ] **오디오**: 음악 바뀜 확인 — 마을 → 폐가(어두운 곡) → 요괴가 쫓아올 때(빠른 곡). 효과음(베기, 정화, 문)이 들린다.
- [ ] 화면이 꺼졌다 켜지거나 다른 앱을 갔다 온 뒤에도 소리가 계속 났다 / 끊겼다.

**막히면 적을 것**: ______________________________

## 구간 4. 역신(보스) 싸움 (보스까지 오는 데 약 5분 + 싸움)
역신: 체력 480. 진짜 얼굴로 바뀌면 시작합니다. 지면 **다락 입구에서 다시 시작**합니다. (요괴도 다시 나옵니다. 정상)

**기록칸**
| 시도 | 죽은 위치/패턴 (독안개·기침 부채꼴·졸개·충격파 중) | 체력 막대 어디까지 깎았나 |
|---|---|---|
| 1 | | |
| 2 | | |
| 3 | | |
| 4 이상 | | |

- **보스에게 죽은 횟수: ____ 회**
- [ ] 체력이 반쯤 되면 역신이 말을 하고 더 빨라진다.
- [ ] 체력이 0이 되면 쓰러지지 않고 **무릎을 꿇는다.** 노래 버튼이 빛난다.
- [ ] 노래로 정화했다. "왕이… 오신다" 말이 나왔다.
- [ ] 난영의 넋이 몸으로 돌아가고 "새벽" 장면으로 넘어갔다. (세이브 자동)
- 난이도 느낌: 너무 쉽다 / 알맞다 / 너무 어렵다
- 안 보이거나 헷갈린 공격(예고 표시): ______________

**막히면 적을 것**: ______________________________

## 구간 5. 임명·작별·끝 (45~55분)
**여기서 확인할 것**
- [ ] 난영이 "노래가 들렸소"라고 한다. "며칠 뒤" 글이 뜨고 대문에 탈이 걸려 있다.
- [ ] 마을 사람에게서 처용탈을 받았다.
- [ ] 집에서 쉬었다 → 밤 → 내관이 와서 왕의 편전으로 갔다.
- [ ] 왕이 말하고 퇴마어사로 임명됐다.
- [ ] 난영과 작별, 1절 가사 글자, "1장 처용가 끝" 글자, 타이틀로 돌아왔다.
- **완주했나**: 끝까지 했다 / 중간에 멈췄다 (멈춘 곳: ______ ) / 못 했다
- 총 걸린 시간: ____분

**막히면 적을 것**: ______________________________

## 마무리 확인 A. 저장·이어하기 (5분)
저장은 **집에서 쉴 때, 관아 의뢰 뒤, 보스 뒤, 임명 뒤**에만 됩니다. 그 사이에 끄면 거기까지는 사라지는 게 지금 설계입니다.
- [ ] 쉰 뒤 브라우저를 완전히 닫았다가 다시 열었다. 타이틀에 **"이어하기"**가 있다.
- [ ] 이어하기를 누르면 마을(밤 포함)에서 시작한다. 레벨·약 개수·엽전이 그대로다.
- [ ] 이어하기 후 다음 이야기로 진행이 된다. (같은 장면을 반복하거나 멈추면 적기)
- [ ] 1장을 끝낸 뒤 "이어하기"를 누르면 어떤 장면이 나오나: ______________

## 마무리 확인 B. 홈 화면에 추가 후 업데이트 (10분)
- [ ] 사파리 공유 버튼 → "홈 화면에 추가". 아이콘이 생겼다.
- [ ] 홈 화면 아이콘으로 실행했다. 주소창 없이 전체 화면이다 / 아니다.
- [ ] **저장 기록은 사파리와 별개일 수 있습니다.** 홈 화면판에서 "이어하기"가 없으면 적어 주세요(오류인지 원래 그런지 개발팀이 판단).
- [ ] 개발팀이 "새 버전 올렸다"고 알린 뒤: 홈 화면 아이콘을 **완전히 닫고(앱 전환 화면에서 위로 밀기)** 다시 열었다. 새 버전 내용이 보였다 / 옛날 그대로다.
  - 알려준 변경 내용: ______________  /  본 것: ______________
- [ ] 옛날 그대로라면: 사파리로 열면 새 버전이 나오나? 예 / 아니오
