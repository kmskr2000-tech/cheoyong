# 챕터2 M4 범위 확정 (프로그래밍팀-M4)

근거 문서: `design/levels/ch2-dokkaebigol.md` §3(경로·해금 6단계) · §4.1(hwagae) · §8(장비) · §10(SC2-11~14, 2절 가사) · §12(T13·T15·T16) · §13(수용 기준), `docs/story-bible.md` 2장, `production/qa/ch2-m3-asset-needs.md`, M3 체크포인트(범위 밖 = SC2-11 이후).
`production/milestones/` 에는 챕터2 M4 항목이 없다(그쪽 "M4"는 3장 「구미호」). 그래서 설계서에서 **M3 가 남긴 바로 다음 조각**을 가장 작은 일관된 단위로 잘랐다.

## M3 후속
- **보스 개시 우측 잘림**: 480폭 화면에서 처용 곁(x≈120)이면 카메라가 맵 왼쪽 끝 limit 에 걸려 [0,480] 만 보이는데 보스(x=460, 반폭 58)는 오른쪽 38px 가 잘렸다. 카메라를 밀어도 limit 때문에 소용없다(실측: 밀기 후에도 중심 240 고정) → **보스 개시 위치만 `anchors.boss` 460→416** (지형·소품·`hall`·`boss_respawn` 불변). 개시 직후 우측 여유 +8px 를 테스트로 고정.
- **감투 효과 문구**: 행낭 '지닌 것'에 감투 두 줄(은신 노출 +0.5초 / 도깨비 계열 정화 속도 +10%) 표시. 획득 토스트도 같은 문구.
