# 디렉터 로그

총괄(디렉터)이 내린 지시, 검토 결과, 승인/보완 요청을 날짜별로 기록한다. 새 항목은 해당 날짜 아래에 추가하고, 날짜가 바뀌면 새 `##` 섹션을 만든다.
형식: `- [종류] HH:MM 대상 — 내용 (근거/산출물)` (예: `- [지시] 21:30 대상 — 내용`). 시각(KST, 24시간제)은 항목을 쓴 시각이다. 종류는 지시 / 검토 / 승인 / 보완요청 / 배포 / 결정 / 결정대기 / 재촉 중 하나. 2026-10-12 21:30 이전 항목은 시각 없이 쓰인 구형식이며 소급하지 않는다.
