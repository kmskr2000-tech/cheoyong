# Milestones: M3~M7 — 챕터 2~5·폴리시·출시

> 윤곽만 둔다. 각 마일스톤은 직전 마일스톤 완료 후 `/sprint-plan`으로 구체화한다 (템플릿 규칙: 다음 층의 에픽은 이전 층이 끝나가기 전에 만들지 않는다). 날짜는 용량 측정 전이라 **추정 구간**이다.

## 챕터 마일스톤 공통 템플릿 (1장 실측에서 추출)

| 항목 | 챕터당 기준 (제안) |
|---|---|
| 플레이 시간 | 60~90분 |
| 레벨 | 허브 1 + 필드 1~2 + 던전 1~2 (레벨 데이터 `levels.gd`) |
| 장면 | SC 20~25개 (바이블 장면 ID) |
| 신규 요괴 | 일반 3~4 + 정예 1 (기믹 포함) + 보스 1 |
| 의뢰 | 2~3 (퇴마 1·한풀이 1 이상) |
| 신규 자산 | 보스 3D 인형 → 도트(`art/boss3d.py` 계열), NPC, 지형(`art/ground3d.py`), 음악 1~2곡 |
| 보상 | 탈 1종, 장신구 1종, 피리 단계 1, 처용가 1절 |
| 사용 스킬 | `/team-level`, `/team-combat`, `/team-narrative`, `/team-audio`, `/team-qa` |
| 종료 기준 | 장 완주 스모크 + 폰 플레이테스트 + 도감·퇴치향 계열 연결 |

## M3 — 2장 「도깨비골」 (목표 ~2026-11-29)
- 허브: 화개 장터(상점·정보). 보스: 두억시니(방망이 소환·감투 은신·짚신 순간이동).
- 신규: 외눈박이·불도깨비·산군·정예 장산범. 해금: 오방탈, 학 피리, 도깨비 상점. 낮/밤 시스템 도입 여부 결정(#7).
- 새 기술: 은신 연출, 소환 졸개, 위치 강제 노출(화염부).

## M4 — 3장 「구미호」 (목표 ~2026-12-13)
- 허브: 경주 귀족가·월지. 보스: 구미호 연화(3페이즈, 환술 분신, 매혹=조작 반전).
- **분기: 처단 vs 한풀이** — 사용자 결정 #4 선행. 엔딩 분기 추적 시스템 사용.
- 신규: 여우 졸개·장승·정예 손각시. 해금: 여우탈, 여우 구슬.
- 추리 요소(증거 3~5개) — 조사 UI는 기존 interact 확장.

## M5 — 4장 「이무기」 (목표 ~2027-01-03)
- 허브: 용궁. 보스: 이무기 뇌룡(**해상전**: 배 갑판, 파도 기울기, 낙뢰 예고, 소용돌이).
- **새 전투 모드** — 착수 전 `/prototype`으로 갑판 이동·기울기 검증(위험 시스템 #23).
- 신규: 파도 요괴·어둑시니·정예 해태. 해금: 가호 계열 스킬, 용탈, 용문 피리, 용궁 세트.
- 형제(해강·해명) 서사 회수.

## M6 — 5장 「역신왕」 (목표 ~2027-01-24)
- 허브: 황천둑. 최종 보스: 역신왕 3페이즈(역병 군단 → 경계 붕괴 → 본체), 피날레 대규모 굿(처용가 5절 합창).
- 신규: 망자(떼·재기립)·저승 파수꾼·정예 불개(일식). 해금: 신선탈, 천년 피리, 처용 세트.
- 엔딩 2종(자비로운/단호한 어사), 처용탈·처용무 전통 접속 연출.

## M7 — 폴리시·출시 (목표 ~2027-02-14)
- 전체 플레이스루(1~5장 연속), 밸런스 패스 `/balance-check`, 성능 `/perf-profile`, 보안 `/security-audit`(세이브 변조 수준), 접근성 점검.
- `/release-checklist` → `/launch-checklist`. 폰 확인 후 "완료".
- 후속(범위 밖): 설문대할망 보스, 인물록·설화 조각, 세이브 슬롯, Android.

## 일정 가정과 한계

- 위 날짜는 **관측한 속도**(1장 핵심이 약 2일, 아트 개편이 며칠)에서 낙관적으로 외삽한 것이 아니라, 스프린트 1주 × 챕터당 2주 가정이다. 스프린트 1·3이 끝나면 실제 용량으로 재산정한다 (`/estimate`, `/sprint-status`).
- 가장 큰 불확실성: 사용자의 폰 플레이 가용 시간, 3장 분기 결정, 해상전 프로토타입 결과.
